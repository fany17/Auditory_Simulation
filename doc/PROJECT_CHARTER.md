# 1. 项目摘要

本项目拟建立一套可持续扩展、可复现、可审计的“听觉时变信息处理与跨模态表征对齐平台”。项目先以大型、经典、许可明确的公开语音/音频数据和可训练听觉神经网络完成跨数据集训练，再结合计算神经仿真和真实神经记录，研究声学、音系、语言、情绪/韵律、运动相关及精细时间信息如何形成、传递、转换、丢失、被读取、被对齐和被调控。

项目分为三条相互依赖但不能混写的科学路线：

- **路线 A：面向脑机接口的计算神经仿真。** 从声音、外周听觉近似、瞬时发放率和 spike train 出发，逐步研究群体活动、宏观状态近似、下游解码与人工调控。
- **路线 B：面向公开数据的可训练听觉神经网络基座。** 核验大型、经典、许可明确的公开语音/音频数据和公开训练配方，完成至少两个独立数据源的跨数据集训练，形成可复现 checkpoint、逐层时间表示和跨域泛化基线。
- **路线 C：真实神经信号表征与听觉—神经对齐。** 使用具有声音刺激或可靠时间标注的 EEG、MEG、fMRI、iEEG/ECoG 数据，建立模态特异的神经表示与低容量对齐层，检验声音表征和神经响应的双向预测及跨被试/跨数据集泛化。

三条路线共享刺激定义、物理时间轴、ground truth、数据切分、评价原则和部分 decoder 规范，但不把人工模型层直接命名为脑区，不把模型中可读出的信息直接解释为真实神经系统的功能机制，也不把异构模型原始参数的逐元素预测默认视为表征对齐。

本项目不以单一分类准确率、单一模型或单一脑区为主轴，而以“公开数据—真实训练—中间状态—跨域评价—神经预测—受控扰动—输出变化”的可证伪实验链为主轴。近期第一优先级是 TB001：完成公开数据核验、可训练听觉基座和跨数据集训练闭环；其后才以冻结基座进入 TC001。TA001 保留为独立机制路线。该优先级不等于已批准具体任务，也不授权下载、训练或启动 Agent B。

# 3. 项目背景与必要性

## 3.1 科学背景

声音是高采样率、连续、强非平稳的时间信号。频谱只能描述其中一部分内容；onset、offset、持续时间、间隔、包络、载波精细结构、相位、节拍、遗漏和跨事件关系同样决定听觉信息的组织方式。

生物听觉系统通过频率分解、非线性换能、压缩、适应、随机发放、群体编码、多尺度积分和反馈逐步改变信息载体。人工时序模型则通过滤波、分帧、下采样、卷积、状态更新、注意力、缓存和学习目标形成中间表示。EEG、MEG、fMRI 与 iEEG/ECoG 又从不同时间、空间和生理尺度观测神经活动。三类系统均可能保存、重编码或丢失特定信息，但状态含义、数据规模和证据标准不同。

现有模型即使能完成语音识别、音频分类或生成任务，也不能仅凭终端性能回答以下问题：

- 局部时间精度在哪个环节开始下降；
- phase、jitter、omission 或事件边界是否仍可从中间层读出；
- 长时间上下文是否以牺牲快速响应为代价；
- 模型的“记忆”实际保存了什么；
- 某个中间变量的变化是否会引起下游功能的可预测变化。

因此，有必要先建立大型公开数据、真实跨数据集训练和外部评价基础，再建立以可控刺激、逐层状态、简单读出器、神经预测、受控扰动和可复现证据为核心的平台。

## 3.2 与脑机接口长期问题的关系

项目与脑机接口长期“读取—理解—调控—写入”路径相关，但近期仅建立计算与算法基础：

1. 读取自然声音在模型状态中形成的可观测变化；
2. 区分局部响应、可解码性、跨条件泛化和功能保持；
3. 检验输入或中间状态的人工改变能否使下游输出按预期变化；
4. 为未来自然输入和人工输入的功能比较提供共同评价坐标。

当前算法仿真不等于临床刺激系统，不自动具备医疗用途，也不能替代人体或动物实验。

## 3.3 项目建设必要性

本项目拟解决以下共性问题：

- 相关研究资产分散在不同工作区，尚未形成当前项目自己的可运行闭环；
- 生物事实、工程近似和研究假设容易混写；
- 终端任务性能不能定位时间信息在何处变化；
- 不同模型常使用不同前端、输入、参数量、延迟和训练预算，难以公平比较；
- 语音、情绪和神经公开数据在规模、标签、语言、刺激和许可上不一致，简单拼接不能形成可信跨数据集基座；
- 失败实验、阴性结果和不可用模型容易被成功结果覆盖；
- 缺少从配置、代码、随机种子、日志、指标到图形的完整 provenance。

# 4. 中心科学问题与研究命题

## 4.1 中心科学问题

> 连续声音中的声学、音系、语言、情绪/韵律、运动相关和精细时间信息，经过可训练听觉网络与不同神经层级后，哪些内容被保留、重编码或丢失；这些中间表征能否在严格时间对齐、跨数据集和 held-out 条件下相互预测，并能否通过人工干预使下游输出按预期改变？

## 4.2 三个核心子问题

### 子问题 A：神经状态近似中的信息形成与传递

声音如何经过外周听觉近似形成 firing rate、spike timing、population activity、oscillation 和 LFP proxy；这些状态分别保留什么时间信息；输入或中间状态被调控后，下游 decoder 和控制输出如何变化？

### 子问题 B：公开数据和可训练听觉基座

大型、经典、许可明确的公开语音/音频数据和成熟自监督架构能否形成一个可实际训练、可跨数据集泛化且保留物理时间轴的听觉基座；哪些数据、目标和结构分别支持声学、音系、语言与情绪/韵律信息？

### 子问题 C：真实神经表征与听觉—神经对齐

不同听觉模型层的时间表征能否预测 EEG、MEG、fMRI、iEEG/ECoG 等真实神经响应；神经表征能否读取语言、情绪/韵律和运动相关变量；这些关系能否跨刺激、跨被试和跨数据集复现？

## 4.3 首批研究假设

以下均为 `H：待验证研究假设`，不是当前结论：

1. 不同信息载体对平均强度、局部相位、事件时间和长期节律的保留能力不同。
2. 下采样、pooling、stride 和 tokenization 可能较早削弱局部时间精度。
3. 单一慢时间尺度可能无法同时兼顾快速事件监测和长时间上下文。
4. 快慢并行通路可能在匹配资源条件下改善局部时间信息与全局上下文的折中。
5. 局部状态相似不必然产生跨条件可读或下游功能相似。
6. 受控扰动只有在基线信息可读且对照充分时，才能提供有限机制证据。
7. 至少两个独立语音/音频数据源的联合或分阶段训练可能提高外部域泛化，但也可能只学到数据集身份或说话人捷径。
8. 声音模型与神经模型的时间对齐中间表示比异构网络原始参数更适合作为默认对齐对象。

# 5. 项目目标

## 5.1 总体目标

建立一套以大型公开数据、真实跨数据集训练、分层状态、跨域评价、真实神经预测、受控扰动、公平比较、可复现运行和独立审核为核心的听觉时变信息与表征对齐平台。

## 5.2 路线 A 目标

1. 建立声音到瞬时发放率和 spike train 的最小仿真闭环。
2. 研究 rate coding、spike timing、population coding 和 oscillatory coding 的信息边界。
3. 建立群体状态和 LFP proxy 的明确 forward approximation。
4. 研究 delay、jitter、noise、adaptation、refractory effect 和 synaptic integration 对信息传递的影响。
5. 建立 held-out decoder，评价信息是否可被下游读取及能否跨条件泛化。
6. 研究输入或中间状态受控改变对下游输出的影响。
7. 为未来自然状态与人工状态的功能比较及闭环调控提供算法基础。

## 5.3 路线 B 目标

1. 建立大型、经典、许可明确的公开语音/音频数据登记表和统一 manifest。
2. 以 [wav2vec 2.0](https://github.com/facebookresearch/fairseq/blob/main/examples/wav2vec/README.md) 作为经典可训练基线、[WavLM](https://github.com/microsoft/unilm/tree/master/wavlm) 作为候选主干、[BEATs](https://github.com/microsoft/unilm/tree/master/beats) 作为通用音频对照；精确版本由任务书冻结。
3. 在至少两个独立公开数据源上完成继续自监督、参数高效训练或分阶段微调，并保存真实 checkpoint 和训练账本。
4. 至少使用一个完整外部数据集进行未参与训练和模型选择的跨域评价。
5. 提取并对齐逐层中间状态，研究声学、音系、语言、情绪/韵律和快速时间信息。
6. 通过数据消融、模块替换和结构消融区分数据规模、训练目标和架构贡献。
7. 在因果或明确伪流式条件下评价延迟、状态、鲁棒性、跨域泛化和资源成本。
8. 为路线 C 提供版本冻结、时间轴明确、可复用且可训练的声音侧锚点。

## 5.4 路线 C 目标

1. 核验具有原始声音或可靠时间标注的公开 EEG、MEG、fMRI 和 iEEG/ECoG 数据。
2. 建立每种神经模态独立的预处理、时间同步、subject/stimulus split 和低容量 baseline。
3. 比较不同听觉模型层和时间 lag 对 held-out 神经响应的预测能力。
4. 检验神经表示对语言、情绪/韵律和运动相关变量的可读性。
5. 在至少一个结果上进行跨被试和外部数据集复现；无法兼容的数据集不得强行联合训练。
6. 区分表征相似、预测对齐、泛化对齐和功能/干预对齐四级证据。

## 5.5 共同目标

三条路线均应回答：

1. 输入变量是否被系统检测到；
2. 中间状态是否包含该变量；
3. 简单 decoder/probe 是否能在 held-out 数据读取该变量；
4. 读取是否能跨强度、频率、噪声、速度、trial、说话人、受试者、数据源或随机种子泛化；
5. 受控扰动是否产生方向可解释、可重复的变化；
6. 局部表示相似是否对应下游功能相似。

### 6.3.3 TA001 候选实现路径

- **路径 A：简化自主实现。** 以 NumPy 或 PyTorch 等可核验组件实现滤波、整流、压缩、适应、瞬时发放率和随机 spike。优点是透明、可测试；边界是不能称为完整听觉神经生理模型。
- **路径 B：历史或成熟模型复现。** 在原始论文、官方实现、许可证、平台、参数和资源全部核验后，选择 Zilany–Bruce–Carney、Meddis、Verhulst/CoNNear 等候选。当前均不得视为已可用。

首个路径由人工在任务书前确认。若成熟模型不可用，应保留简化基线而不是猜测替代实现。

## 6.4 路线 B：公开数据与可训练听觉神经网络基座

### 6.4.1 四个分离的分析层级

1. 输入前端：波形、频谱、复数/相位表示、frame 或 token。
2. 基础算子：卷积、递归、attention、state-space、pooling、stride、nonlinearity。
3. 网络拓扑：串行、残差、多尺度、快慢并行、反馈和缓存。
4. 学习与评价：训练目标、预训练任务、probe、切分、扰动、流式与资源。

不能因为一个模型具有某种拓扑，就把观察到的全部结果归因于单一基础算子。

## 6.6 三条路线的汇合

三条路线只有在相应前置最小闭环通过后才进入汇合审查。最低条件包括：

- 表示相似、可解码性、跨条件泛化和功能保持被明确区分；
- 不进行未经证据支持的脑区—模型层命名。

- TC001 的刺激—神经同步、subject/stimulus split 和 null 可重建。

候选汇合实验包括共同 decoder、matched perturbation 和自然/人工输入的跨条件读取。具体首次汇合变量待定。

## 7.2 阶段 1：可运行基线与信息变化观察

### 路线 A

完成 TA001，建立声音→rate→spike→decoder→扰动闭环。

### 路线 B

完成 TB001：至少两个独立公开数据源真实参与参数更新，一个完整外部数据集只用于评价；保存 checkpoint、训练曲线、数据采样账本、逐层时间表示和跨域结果。

### 路线 C

在 TB001 checkpoint 冻结后，使用 SparrKULee 或 MEG-MASC 候选完成 TC001 的刺激—神经同步和低容量 encoding/decoding baseline。

### 阶段门槛

- 时间轴、单位、状态和随机性可验证；
- 至少一种目标属性可在 held-out 数据读取；
- 结果跨 seed 或重复稳定；
- 配置、日志、指标和图可从真实输出重建；
- 阴性结果和替代解释被保留。
- 跨数据集训练可以从日志、采样账本和 checkpoint 证明真实发生；
- 神经路线结果按 subject/stimulus held-out，并通过时间错配和传统声学 null。

## 7.3 阶段 2：机制、扰动与结构修改

### 路线 A

根据阶段 1 结果扩展到群体、宏观状态、跨层传递和受控扰动。

### 路线 B

根据 TB001 中观察到的数据域和层级信息变化开展数据消融、模块消融、快慢通路、动态时间常数或事件驱动研究。

### 路线 C

比较 layer×lag×sensor/ROI，开展跨被试、跨数据集和混杂控制；不能把数据集身份识别当成共同神经表示。

### 阶段门槛

- 每轮只改变一个主要因素；
- 参数量、前端、训练预算、look-ahead 和计算资源尽可能匹配；
- 结构改动的效果不能仅由标签泄漏或额外资源解释；
- 机制结论具有预注册的 no-go 条件。

## 7.4 阶段 3：下游功能、人工调控与跨系统比较

### 路线 A

研究自然/人工输入、下游 decoder、控制输出和闭环稳定性。

### 路线 B

研究实时因果处理、状态控制、资源 Pareto，并输出路线 C 可复用的冻结适配接口。

### 路线 C

研究声音或共享 latent 干预对神经预测和语言、情绪/韵律、运动相关下游输出的影响。

### 阶段门槛

- 人工干预产生方向可解释的下游变化；
- 跨条件 decoder 或功能保持证据成立；
- 局部表示相似不被夸大为功能等价；
- 安全、资源和应用边界明确。

# 8. 研究方法与共同规范

## 8.1 证据状态

所有项目文档、代码注释、图表和结论使用以下状态：

| 标记 | 含义 | 使用要求 |
|---|---|---|
| P | 项目已确认目标 | 可组织任务，不能写成实验结果 |
| E | 外部证据支持事实 | 回到论文或官方资料，保留适用范围 |
| I | 工程实现建议 | 说明是可替换的实现选择 |
| H | 待验证研究假设 | 预先定义对照和失败条件 |
| V | 长期愿景 | 不写成当前能力或临床结论 |

## 8.2 输入与 ground truth

每个刺激至少记录：

- canonical stimulus id 和版本；
- waveform 或生成参数；
- sample rate、duration、channel 和单位；
- frequency、intensity 或数字幅值约定；
- onset、offset、expected onset 和事件列表；
- phase、AM/beat、jitter、omission 等任务变量；
- random seed、生成代码和哈希；
- train/validation/test 归属及切分依据。

数字幅值不自动等于校准声压级；没有物理校准时必须明确写为数字幅值或相对强度。

## 8.3 中间状态与时间对齐

每一层状态应记录：

- 状态名称、shape、dtype 和单位；
- 输入采样率与输出更新率；
- receptive field、stride、chunk、look-ahead 和算法延迟；
- frame/token/hidden state 到物理时间的映射；
- 是否 causal、伪流式或离线；
- 缺失、padding、边界和滤波延迟处理。

## 8.4 Decoder 与 probe

- 优先使用线性或其他低复杂度读出器；
- 原模型默认冻结，除非任务书明确研究联合训练；
- decoder 训练和评估严格分离；
- split 不允许同一生成族、speaker/source、trial 或高度相关片段泄漏；
- 可读性不等于模型显式使用，不等于因果，也不等于生物真实 decoder；
- 至少与机会水平、置换标签或 matched null 比较。

## 8.5 扰动与消融

每项扰动必须写明：

- 唯一主要改变因素；
- 冻结因素；
- 参数范围和选择理由；
- matched control；
- 预期方向；
- 可证伪条件；
- 对资源、延迟和其他性能的影响。

## 8.6 统计与重复性

具体阈值待任务级预注册，但至少遵循：

- 报告跨 seed、trial 或刺激的变异；
- 主要与探索性指标分开；
- 多重比较时说明校正策略；
- 避免只报告最好一次运行；
- 失败、发散、超时、无效 seed 和 no-go 均保留；
- 图表包含样本、条件、单位和不确定性信息。

## 8.7 可复现性与 provenance

每项结论应能够回指：

```text
task_id
→ experiment_id
→ immutable run_id
→ config version
→ code version or snapshot
→ environment record
→ input/stimulus version
→ random seed
→ raw output
→ metric script and table
→ figure script and file
→ execution report
→ review report and human decision
```

不得仅以 `final`、`new`、`latest` 或 `best.pt` 作为唯一标识。

Agent A 提出审核建议，人工作最终决定。没有人工确认不得自动进入下一编号任务。

# 11. 质量、验收与决策门槛

## 11.1 通用质量维度

| 维度 | 最低要求 |
|---|---|
| 正确性 | 时间轴、单位、shape、状态和随机性正确 |
| 可读性 | held-out decoder/probe 超过预注册 null 或机会水平 |
| 稳定性 | 跨 seed、刺激或重复具有可解释稳定性 |
| 跨数据集性 | 至少两个独立数据源真实参与训练；一个完整数据源外部评价；分别报告最差域和宏平均 |
| 可解释性 | 操纵方向明确，替代解释和伪影被检查 |
| 可复现性 | 配置、代码、日志、结果、指标和图可重建 |
| 资源可行性 | 运行时间、内存、磁盘、延迟符合任务预算 |
| 证据边界 | 事实、近似、假设、愿景和阴性结果分开 |

具体数值阈值必须在对应任务开始前依据 baseline、随机变异和应用需求预注册；本项目书不虚构统一阈值。

## 11.2 路线 A 近期 go/no-go

### Go 候选

- frequency、intensity 或时间变化产生方向合理的 rate/spike 改变；
- 至少一种属性可在 held-out 数据读取；
- 时间扰动产生可解释变化；
- 跨 seed 稳定；
- 测试、指标和图可以重建。

### No-go / 转向候选

- 结果主要由 bin width、滤波边缘、随机数实现或标签泄漏决定；
- 最早载体中目标信息不可读；
- 模型参数不可辨识或成熟模型无法合法获得；
- LFP proxy 缺少可审计 forward assumption；
- 中间状态变化不能引起任何下游功能变化。

## 11.3 路线 B 近期 go/no-go

### Go 候选

- 至少一个 baseline 和一个代表模型可稳定运行；
- 至少两个独立公开数据源真实参与参数更新并留下可审计 checkpoint；
- 至少一个完整外部数据集与模型选择隔离，跨域结果超过预注册强基线或形成明确 no-go；
- 中间层和时间轴可恢复；
- probe 切分无明显泄漏；
- 层间信息变化可重复；
- causal 或伪流式评估边界清楚。

### No-go / 转向候选

- 模型许可不符、权重不可得或隐藏层接口不可用；
- 优势在参数量、前端、look-ahead 或训练预算匹配后消失；
- probe 结果对切分、维度或正则极不稳定；
- 局部时间改进带来不可接受的内容、鲁棒性或资源损失；
- 当前数据无法区分提出的机制假设。
- 数据/模型许可不允许联合训练或结果发布；
- 所谓跨数据集训练只发生在混合后随机切分，或主要由说话人、故事、数据集身份泄漏解释。

## 11.4 路线 C 近期 go/no-go

### Go 候选

- 神经数据、刺激、同步、预处理和 subject/stimulus split 可以重建；
- 至少一个 held-out encoding/decoding 或 match/mismatch 指标超过预注册 null；
- 深层表示相对声学包络、随机模型或时间错配对照提供可重复增益；
- 结论在至少一个跨被试或外部数据设置中复现。

### No-go / 转向候选

- 数据许可、刺激获取或同步无法审计；
- 结果由相邻窗口、刺激身份、说话人、受试者或数据集身份泄漏解释；
- 不同神经数据集的任务和标签不兼容，无法支持同一主张；
- 只有表征相关，没有 held-out 预测增益。

| 风险 | 可能影响 | 预防与应对 | 当前状态 |
|---|---|---|---|
| 科学路线混写 | 把人工层解释为脑区、把生理事实直接模块化或混写神经模态 | TA/TB/TC 独立任务、证据标签、汇合门禁 | 已纳入原则 |
| 模型生理解释过度 | 工程近似被写成真实生理机制 | 记录方程、参数来源、物种与适用范围 | 待任务落实 |
| 数据泄漏 | probe 或分类指标虚高 | 生成族/source/seed 分组切分和置换对照 | 规范待冻结 |
| 跨数据集伪泛化 | 同说话人、故事、派生音频或数据集身份跨 split | source/speaker/story/dataset 分组；完整外部数据集隔离 | 已纳入 TB001 门禁 |
| 数据源失衡 | 最大数据集主导训练并掩盖小域失败 | 显式采样权重、有效小时数、最差域与宏平均 | 具体权重待任务冻结 |
| 标签本体冲突 | ASR、语言、情绪标签不可直接拼接 | 多任务头、缺失标签掩码、映射表和不可映射状态 | schema 待冻结 |

| 前端和资源不公平 | 错误归因于模型结构 | 前端、参数、FLOP、延迟、预算匹配 | 任务级落实 |
| 随机性不稳定 | 单次阳性结果不可复现 | 多 seed、固定随机源、记录失败 seed | 阈值待定 |

| 公开不等于可联合训练 | 数据可下载但许可禁止组合、再分发或某类用途 | 每个数据源独立许可审计，禁止用“公开”替代授权 | 候选已列，任务级许可待定 |
| 神经模态混写 | EEG/MEG/fMRI/iEEG 被当成同一层级或统一采样 | 模态特异 encoder、同步、指标和结论 | 路线 C 原则已冻结 |
| 参数对齐误判 | 异构模型参数映射被误写成表征/机制同一 | 默认对齐中间表示和 held-out 预测；参数映射仅限可辨识假设 | 已纳入边界 |
| 硬件不足 | 大模型或批量实验无法完成 | 优先最小模型、短刺激、CPU 方案和资源上限 | 硬件待确认 |
| 失败证据被覆盖 | 产生选择性汇报 | 不可变 run_id、artifact 索引、失败归档 | 工作流待建立 |
| 无可靠回滚 | 修改后无法恢复基线 | Git 或无 Git 快照、manifest 和哈希 | 当前未启用 Git；重要操作须先建立可恢复保护 |
| 数据与隐私风险 | 真实 EEG/LFP 使用越界 | 数据授权、去标识、访问与同步审查 | 未接入真实数据 |
| 临床外推 | 算法结果被误写为医疗能力 | 明确非临床、非医疗用途边界 | 已纳入原则 |

# 13. 数据、环境、资源与合规

## 13.1 数据计划

### 第一阶段：公开语音数据与可训练基座

TB001 必须先建立数据登记表并冻结至少两个独立训练数据源和一个完整外部评价数据源。当前优先候选为：

- LibriSpeech：约1000小时、经典英语ASR/音系锚点；
- Libri-Light：60,000小时以上无标注语音，自监督规模候选；
- Mozilla Common Voice：多语言及普通话/英语跨域候选；
- MSP-Podcast v2.0：409小时自然情绪/韵律候选；
- IEMOCAP：经典情绪外部评测候选。

首个可执行组合建议为 LibriSpeech + 一个冻结版本的 Common Voice 参与训练，另取完整独立语料作外部评价；情绪分支以 MSP-Podcast 训练、IEMOCAP 外部评测。最终组合必须依据访问、许可、标签兼容和资源重新批准，不能把本建议写成已经获得数据。

程序生成、参数完全已知的合成声音仍用于时间轴、phase、jitter、omission 和机制 probe，不再替代真实语音跨数据集训练。

### 第二阶段：公开神经配对数据

TC001 第一候选为 SparrKULee 或 MEG-MASC；后续以 Narratives 和 Brain Treebank 扩展语义与侵入式层级。每个神经数据集分别记录受试者、刺激、通道/ROI、电极、采样率、预处理、同步、许可和隐私边界。没有共同刺激或共同标签的数据集只能通过明确 ontology 或外部评价形成弱桥接，不能宣称样本级直接对齐。

真实语音、环境声、EEG、LFP 或其他脑信号只有在来源、许可证、伦理、隐私、同步和访问权限确认后才接入。当前不把候选数据、其他工作区数据或网页可下载状态自动视为本项目资产。

### 跨数据集训练最低规则

- 至少两个独立数据源真实参与参数更新；
- 至少一个完整数据源只用于外部评价；
- 同一说话人、故事、电影、播客、书籍章节和派生音频不得跨 split；
- 保存每个数据源的有效小时数、丢弃比例、采样权重、训练步数和损失；
- 报告单数据集训练、联合/分阶段训练和冻结特征强基线；
- 分别报告同域、外域、最差域、宏平均和失败域；
- 跨数据集 checkpoint 必须能由配置、manifest、日志和随机种子重建。

# 17. 明确不做或不能声称的事项

在相应证据和批准出现前，本项目不能：

- 声称当前已有可运行模型、数据集、环境、权重或实验结果；
- 把简化滤波、整流、随机 spike 或卷积结果称为完整真实听觉生理；
- 把 spike 简单卷积直接称为临床 LFP；
- 把人工网络层直接命名为听神经、听觉皮层、STN 或其他脑区；
- 把 probe 可读写成模型显式编码、因果使用或生物功能；
- 把局部表示相似写成功能等价；
- 把离线模型写成因果或实时模型；
- 把单次最佳 seed、单一漂亮图或终端分类准确率作为机制结论；
- 隐藏失败运行、阴性结果或任务偏差；
- 未经许可下载、再分发或使用外部数据、代码和模型；
- 把算法仿真写成临床刺激能力、治疗建议或医疗产品。
