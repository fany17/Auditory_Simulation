- **路线 A：面向脑机接口的计算神经仿真。** 研究声音如何转化为发放率、spike、群体活动、振荡和 LFP 等状态，以及这些状态如何被下游读取和调控。
- **路线 B：面向公开数据的可训练听觉神经网络基座。** 以大型、经典、许可明确的语音/音频数据集和公开训练配方为起点，完成至少两个独立数据源上的跨数据集训练，并研究模型如何保存声学、音系、语言、情绪/韵律和快速时间信息。
- **路线 C：真实神经信号表征与听觉—神经对齐。** 在 EEG、MEG、fMRI、iEEG/ECoG 等真实公开数据上建立模态特异的神经表示，检验听觉模型中间表征能否预测神经响应、神经表征能否读取任务变量，以及共享表示能否跨被试、跨刺激和跨数据集泛化。

截至本总纲首次编制时，当前 `Auditory_Simulation` 目录内没有已确认的模型实现、数据集、环境、实验结果或正式任务书。本文件只建立长期研究框架，不把上级目录或其他工作区中的相关项目资产自动视为本项目已经完成的工作。2026-08-07 归入 `test/` 的 `02_`、`03_` 系列与 `test/deliverables/` 属于测试、验证或演示材料，除非后续获得正式任务书、执行报告、审核报告和人工接受决定，否则仍不计为整体项目已完成资产。

# 1. 项目定位

## 1.1 中心科学问题

项目围绕一个共同问题展开：

> 连续声音中的声学、音系、语言、情绪/韵律、运动相关和精细时间信息，经过可训练听觉网络与不同层级神经系统后，哪些内容被保留、重编码或丢失；这些中间表征能否在严格时间对齐、跨数据集和 held-out 条件下相互预测，并能否通过受控干预使下游输出按预期改变？

这一问题需要同时观察三类系统：

1. **神经计算系统**：从外周听觉近似、spike 和群体状态出发，研究生物启发的信息载体及其传递；
2. **人工听觉系统**：从大型公开语音/音频数据、信号处理前端、时序算子、网络拓扑和学习目标出发，研究可训练基座的信息保存、迁移与遗忘；
3. **真实神经记录系统**：分别处理 EEG、MEG、fMRI、iEEG/ECoG 等观测尺度，研究其与声音和任务变量的时间锁定表征及跨模态可预测性。

三条路线共享刺激、时间变量和“输入—中间状态—下游读取—扰动—输出变化”的实验逻辑，但不共享未经验证的功能解释。

## 1.2 为什么必须分成三条路线

路线 A、B、C 的研究对象不同：

- 路线 A 的对象是 firing rate、spike timing、population activity、oscillation、LFP proxy 和 decoder 等神经状态或神经状态近似；
- 路线 B 的对象是公开语音/音频数据、waveform/frame/token、hidden state、feature map、recurrent state、attention/SSM state、缓存和逐层表示等人工模型状态；
- 路线 C 的对象是真实 EEG、MEG、fMRI、iEEG/ECoG 数据及其模态特异的预处理、空间位置、采样时间、受试者和任务标签。

二者也使用不同的证据：

- 路线 A 需要生理事实、模型方程、物种与记录条件、随机发放统计以及下游功能验证；
- 路线 B 需要数据版本与许可、模型版本、输入前端、训练目标、隐藏层接口、跨数据集采样、计算资源、probe、防泄漏切分和消融结果；
- 路线 C 需要数据伦理与访问边界、BIDS/元数据、刺激—神经时间同步、受试者/刺激切分、跨模态 adapter、神经预测和替代解释对照。

如果过早混写，就会出现三类错误：把人工网络层直接命名为脑区、把生理现象直接当成可复用工程模块，或把不同受试者、刺激和模态的数据拼接后误称为样本级对齐。因此，项目先建立可审计的数据与听觉基座，再分别建立仿真和真实神经闭环，最后在共享刺激、时间轴和共同 decoder 层面汇合。

# 2. 项目背景

## 2.1 科学背景

听觉输入是高采样率、连续、强非平稳的时间信号。声音的内容不仅由频谱决定，还依赖 onset、offset、包络、载波精细结构、相位、节拍、持续时间、间隔、遗漏和跨事件关系。听觉系统并非一次把波形压缩为一个低维向量，而是在频率分解、非线性换能、适应、群体发放、并行通路、多尺度积分和反馈中逐步改变信息载体。

现有人工模型可以完成语音识别、音频分类或生成任务，但最终任务性能并不直接回答：局部时间精度在哪一层被削弱，遗漏信息是否仍可读，phase 是否在前端已丢失，长上下文是否以牺牲快速响应为代价，或者模型的“记忆”究竟保存了什么。

因此，本项目选择“信息载体与信息变化”作为主轴，而不是以某个模型名称、某个脑区或某项分类准确率作为主轴。

## 2.2 与脑机接口长期问题的关系

本地项目背景材料把更长期的脑机接口问题表述为“读取—理解—调控—写入”：先识别自然输入在神经系统中形成的状态，再研究人工调节能否重建关键低维变量，并验证下游网络或行为是否能够读取。

对当前算法项目而言，这一背景提供的是目标约束，而不是已完成事实：

- 需要区分局部响应、可解码性、跨条件泛化和功能保持；
- 需要先从低维、可解释的时间变量开始；
- 需要避免把 STN 或任何单一节点当成高保真听觉发生器；
- 需要把自然输入、人工输入和下游功能放在同一可检验框架中；
- 当前算法仿真不等于临床刺激系统，也不自动具备医疗用途。

# 3. 三个核心目标

## 3.1 核心目标 A：面向脑机接口的计算神经仿真

> 建立从可控声音、外周听觉近似、瞬时发放率、spike train 和神经群体活动到 LFP 或其他宏观状态近似、下游 decoder 与控制输出的分层仿真框架，研究不同时间信息在各载体中如何形成、传递、转换、丢失、被读取，并检验输入或中间状态调控如何改变下游功能。

核心问题是：

> 自然听觉输入经过感受器、神经元群体和不同神经层级后，如何表现为 firing rate、spike timing、population activity、oscillation、LFP 和下游可读取状态；当输入或中间环节被调控时，下游信息会发生什么变化？

该目标服务于脑机接口的“读取—理解—调控—写入”逻辑，但近期只构建计算闭环，不声称完成临床写入。

## 3.2 核心目标 B：面向公开数据的可训练听觉神经网络基座

> 建立面向连续声音的可训练听觉神经网络基座：使用大型、经典、许可明确的公开语音/音频数据，完成至少两个独立数据源的跨数据集训练，形成从声学与快速时间变量到音系、语言、说话人和情绪/韵律变量的分层表示，并保留可复现训练、逐层提取、probe、扰动、消融和迁移评价接口。

核心问题是：

> 经典公开语音/音频数据和成熟自监督架构能否形成一个可实际训练、可跨数据集泛化且保留物理时间轴的听觉基座；哪些训练数据、任务目标和模型结构分别支持声学、音系、语言与情绪/韵律信息，并为后续真实神经表征对齐提供稳定锚点？

该目标不是单纯的精度竞赛，也不要求从零重训超大模型。项目优先采用公开权重加继续自监督训练、参数高效训练或分阶段微调，并以 [wav2vec 2.0](https://github.com/facebookresearch/fairseq/blob/main/examples/wav2vec/README.md) 作为经典可训练基线、[WavLM](https://github.com/microsoft/unilm/tree/master/wavlm) 作为全栈语音候选主干、[BEATs](https://github.com/microsoft/unilm/tree/master/beats) 作为通用音频对照；精确版本、权重和许可证仍由正式任务书冻结。

## 3.3 核心目标 C：真实神经信号表征与听觉—神经对齐

> 在具有原始听觉刺激或可靠时间标注的公开 EEG、MEG、fMRI、iEEG/ECoG 数据上建立模态特异的神经编码器和低容量对齐层，比较听觉模型不同层级表征对神经响应的预测能力，并检验神经表征对语言、情绪/韵律和运动相关变量的可读性、跨被试泛化与跨数据集复现。

对齐对象原则上是时间对齐的中间表示、预测输出和任务变量，而不是两个异构模型的原始参数。参数因置换、缩放、旋转和架构差异而不可直接识别；只有在共享架构与明确可辨识约束下，参数映射才可作为后续研究假设。

## 3.4 三个目标的共同约束

三条路线都必须回答：

1. 输入变量是否被系统检测到；
2. 中间状态是否包含该变量；
3. 简单下游 decoder 是否能读取该变量；
4. 读取是否能跨强度、频率、噪声、速度、说话人、受试者、数据源或随机种子泛化；
5. 对输入或中间状态的受控扰动是否产生可预测变化；
6. 局部表示相似是否对应下游功能相似。

路线 A 不用生物名词为路线 B 提供未经验证的功能标签；路线 B 不用模型性能替代路线 A 的生理解释；路线 C 不把相关、可解码或表征相似写成神经机制同一、显式使用或因果作用。

# 4. 路线 A：脑机接口与计算神经仿真

## 4.1 研究对象与信息流

路线 A 从可解释、可验证的最小单元开始，不要求近期完整复刻所有听觉核团。基本信息流为：

```text
声音输入
→ 频率分解
→ 换能与压缩
→ 听神经样瞬时发放率
→ spike train
→ 群体活动
→ LFP或其他宏观状态近似
→ 下游信息读取
→ 输入或中间状态调控
→ 下游变化
```

这里的箭头表示计算依赖，不表示真实听觉通路严格串行。真实系统包含并行通路、局部复发、跨级投射和下行反馈；初期流程图只是为了建立可测试接口。

## 4.2 主要研究对象和术语

### 4.2.1 输入、频率通道和外周换能

| 对象 | 本项目中的操作定义 | 解释边界 |
|---|---|---|
| **声音波形** | 带物理时间轴和采样率的声压代理序列 | 数字幅度不自动等于校准声压级 |
| **频率通道** | 由滤波器组得到的窄带或子带信号 | 通道不是一条真实听神经纤维 |
| **耳蜗样滤波** | gammatone、解析滤波器组或其他频带依赖滤波近似 | 是工程近似，不等于完整耳蜗力学 |
| **毛细胞样换能和压缩** | 整流、饱和、幂律/对数压缩、低通与适应的组合 | 参数含义需标明是生理来源还是工程设定 |
| **听神经瞬时发放率** | 随时间变化的条件强度函数 \(\lambda(t)\) | 是 spike 生成概率的模型量，不是实测放电 |
| **adaptation** | 持续刺激下响应随时间减弱或动态范围改变 | 快慢适应需分开，不能用单一衰减代表全部机制 |
| **refractory effect** | spike 后短时间内再次放电概率降低 | Poisson 无不应期；需用更新过程或显式规则扩展 |

### 4.2.2 单神经元和群体脉冲

| 对象 | 本项目中的操作定义 | 主要用途 |
|---|---|---|
| **spike train** | 离散 spike 时间点集合或二值时间序列 | 研究事件时间、相位锁定和随机性 |
| **spike timing** | spike 相对载波、包络、节拍或事件的时间关系 | 与平均 firing rate 分开评价 |
| **population spike / population activity** | 多个单元 spike 的群体计数、时间模式或低维状态 | 研究冗余、同步与 population coding |
| **PSTH** | 多 trial 或多单元按事件对齐后的时间直方图 | 观察 onset、持续响应和适应 |
| **inter-spike interval（ISI）** | 相邻 spike 的时间间隔分布 | 检查不应期、规则性和 burst 候选 |
| **phase locking** | spike 对周期相位的稳定锁定 | 需要明确锁定对象和频率范围 |
| **vector strength** | spike 相位集中程度的圆统计量 | 高值不自动等于信息可被行为使用 |
| **bursting** | 短时高密度 spike 事件，按预定义规则识别 | 是否适用于选定听神经/下游模型需核验 |
| **population synchrony** | 多单元在时间或相位上的共同变化 | 需区分共同输入与真实耦合 |

### 4.2.3 振荡、LFP 和下游读取

| 对象 | 本项目中的操作定义 | 解释边界 |
|---|---|---|
| **oscillatory activity** | 群体状态在特定频率范围内呈现的周期或准周期变化 | 频谱峰不自动证明独立振荡器 |
| **LFP proxy** | 由突触电流、膜电流或群体活动经明确 forward approximation 得到的宏观信号 | 不能把 spike 简单卷积结果直接称为真实临床 LFP |
| **LFP power/phase** | 对 LFP proxy 的频带功率和相位描述 | 受滤波、参考和生成模型影响 |
| **cross-frequency coupling** | 低频相位与高频振幅/事件率等的统计耦合 | 必须排除波形非正弦、边缘和共同驱动伪影 |
| **群体输入输出关系** | 上游 spike/状态到下游神经群体状态的映射 | 可包含 delay、jitter、抑制、突触积分和噪声 |
| **downstream decoder** | 从当前载体预测已知输入变量的受控读出器 | 可读不等于因果、专属或生物实际 decoder |
| **控制节点** | 接收 decoder 或神经状态并产生离散/连续控制输出的模型模块 | 是工程接口，不直接等同真实运动核团 |

## 4.3 长期研究目标

路线 A 的长期目标是：

1. 建立从声音到 spike、population activity 和 LFP proxy 的分层仿真框架；
2. 理解 firing rate、spike timing、population code 和 oscillatory state 分别保留了什么；
3. 研究频率、强度、包络、节拍率、相位、遗漏和预测误差信息如何逐层变化；
4. 研究 adaptation、delay、jitter、noise、synaptic integration 和 population coupling 对信息传递的影响；
5. 比较 rate coding、temporal coding、population coding 和 oscillatory coding；
6. 研究输入或中间状态被人工调节后，downstream decoder 和控制输出如何改变；
7. 为未来自然输入、人工刺激输入和下游读取之间的功能比较建立算法基础；
8. 为脑机接口中的“读取—理解—调控—写入”提供可检验的计算模型。

## 4.4 短期最小闭环：TA001

TA001 的任务定义固定为：

> 建立听神经或听神经样神经群体的 spike 仿真，验证不同频率、强度和时间结构输入如何改变瞬时发放率与 spike timing。

最小闭环为：


TA001 的核心不是做出最复杂的生物模型，而是回答：

- 不同纯音频率是否激活不同通道；

- adaptation 如何改变持续响应；
- AM 和节拍输入是否在 spike timing 中保留；

- 时间常数、噪声和随机性如何影响下游可读性。

### 4.4.1 路径 A：简化自主实现

候选组件包括：

- filterbank 或 gammatone；
- 简化毛细胞样换能；
- 非线性压缩；
- 快/慢 adaptation；
- instantaneous rate；
- Poisson、带不应期更新过程或其他 spike generation；

- Brian2；

首轮可以只实现瞬时发放率，再扩展 spike；可以先单通道，再扩展神经群体；可以先确定性刺激，再增加噪声和随机性。Brian2、LIF 或其他框架只有在帮助回答科学问题时才加入，不能为了“更像神经仿真”而无意义增加复杂度。

### 4.4.2 路径 B：历史或成熟模型复现

候选方向包括：

- Meddis 类突触或听神经模型；
- Zilany 类 auditory-nerve model；
- Bruce–Carney 类模型；
- Verhulst 类外周听觉模型或经核验的代理模型；

# 5. 路线 B：公开数据与可训练听觉神经网络基座

## 5.1 研究假设

路线 B 明确提出但尚未证明的研究假设是：

> 当前很多模型以内容识别或全局表征为主要目标，在下采样、池化、分块、tokenization 和长上下文整合过程中，可能牺牲局部时间精度。听觉系统可能通过并行的快速变化检测和慢速上下文整合，避免完全依赖单一时间尺度。

该假设必须通过模型复现、逐层 probe、输入扰动、模块消融、参数/延迟匹配和结构对照检验。若强基线在相同约束下已经保留所需时间信息，或快慢通路只带来参数量/计算量增加，本假设可以被否定或收缩。

## 5.2 四个必须分开的分析层级

| 层级 | 核心问题 | 示例 | 典型风险 |
|---|---|---|---|
| **输入前端 frontend** | 原始波形如何分解、分帧、压缩和采样 | STFT、log-mel、cochleagram、codec/tokenizer | phase/TFS 在进入主干前已丢失 |
| **时序算子 operator** | 信息如何沿时间保存、传播、选择和遗忘 | convolution、RNN/GRU/LSTM、attention、SSM | 把长理论上下文误写成有效记忆 |
| **网络拓扑 topology** | 算子如何连接、分支和跨尺度融合 | residual、U-Net、pyramid、dual-stream | 把 ResNet/U-Net 当成独立时序算子 |
| **学习目标 objective** | 哪些信息因损失函数和数据而被保留 | 分类、重建、masked/contrastive、预测 | 把训练目标形成的能力全归因于结构 |

任何对比如果同时更换前端、主干、训练目标和参数规模，只能称为系统对比，不能用于证明某个基础算子的因果作用。

## 5.3 主要目标

路线 B 的主要目标包括：

1. 建立大型、经典、许可明确的公开语音/音频数据登记表和统一数据 schema；
2. 复现至少一个公开、可训练且能提取逐层时间表示的经典语音基座；
3. 在至少两个独立公开数据源上完成可审计的跨数据集继续预训练、参数高效训练或分阶段微调；
4. 分离数据域、语言、说话人、标签体系和任务目标的贡献，避免简单拼接造成泄漏或大数据源支配；
5. 理解 convolution、recurrence、attention、state-space、pooling、stride、tokenization 和 context window 如何处理时间；
6. 检查声学、音系、语言、说话人、情绪/韵律和快速时间信息在不同模块中如何被压缩和重编码；
7. 通过模块增加、删除、替换和消融，理解各算子的作用；
8. 探索快慢通路、多时间尺度、事件驱动和动态采样机制；
9. 在因果或明确伪流式条件下比较准确性、时间精度、跨域泛化、计算量和延迟；
10. 为路线 C 的真实神经表征预测提供版本冻结、时间轴明确且可训练的声音侧锚点。

## 5.4 关键术语

- **probe**：固定上游表示，用低容量读出器预测已知变量的实验。线性 probe 可回答“该表示是否含有近似线性可读信息”，不能单独证明模型主任务使用了该信息。
- **ablation（消融）**：删除、替换、置零或打乱特定模块/信息，并在其他条件尽量匹配时观察变化，用于机制归因。
- **causal（因果计算）**：时刻 \(t\) 的输出不使用 \(t\) 之后输入。它是流式的必要但非充分条件。
- **streaming（流式）**：输入到达时可增量更新，并明确缓存、chunk、look-ahead、首输出延迟、稳态延迟和状态重置。
- **伪流式**：用滑窗或分块模拟在线输入，但模型内部可能重复计算或使用有限未来信息；必须显式报告。
- **有效感受野/上下文**：在实际参数和任务下，对当前输出产生可测影响的历史范围，不等同于理论最大范围。
- **tokenization**：把连续输入转换为帧、patch、code 或事件 token；它本身可能改变时间边界和物理时间分辨率。

| 真实神经—fMRI | [Narratives](https://fcon_1000.projects.nitrc.org/indi/retro/Narratives.html) | 345 人、891 次扫描、27 个故事 | 语义层级、跨被试与低时间分辨率对照 | 核心数据 CC0；声音刺激使用边界需单独遵守 |
| 真实神经—iEEG | [Brain Treebank](https://papers.nips.cc/paper_files/paper/2024/hash/aefa2385b3f33abf1526ae4e2c208cd9-Abstract-Datasets_and_Benchmarks_Track.html) | 10 人、约 43.5 小时、223,068 个词及 1,688 电极 | 自然语言、侵入式时间—空间对齐 | 电影任务带视觉/情境混杂，许可与访问需核验 |

声音侧“足够大”以小时数、说话人数、语言/域覆盖和有效可用比例共同判断；神经侧“足够大”以受试者数、每人时长、通道/电极覆盖、刺激重复和时间标注质量共同判断，二者不使用同一小时数阈值。

### 5.5.3 代表模型的选择门禁

选择 TB001 预训练模型前必须确认：

1. 官方或作者认可的权重仍可合法获取；
2. 许可证允许本项目的研究使用、缓存和结果发布；
3. 版本、前端、采样率和输入限制明确；
4. 能够稳定提取逐层时间序列，而非只有最终 pooled embedding；
5. 每层输出时间轴和下采样倍率可恢复；
6. GPU/CPU、内存和磁盘需求处于当前资源范围；
7. 离线、causal、streaming 或伪流式能力有官方依据；
8. 官方或作者实现提供训练、继续训练或微调路径，而不只是推理接口；
9. 可以在当前资源下采用 Base/Small、adapter、LoRA、冻结前端或梯度累积形成真实训练闭环；
10. 不需要在 TB001 从随机初始化重训超大基础模型。

任一字段无法确认时标记“待核验”，不能把模型写入已冻结基线。

### 5.5.4 TB001 最低组成

TB001 至少包含：

- 一个传统信号处理基线；
- 一个简单可训练时序基线；
- 一个代表性预训练模型；
- 至少两个独立公开数据源及其统一 manifest；
- dataset_id、source_id、speaker_id、language、task、license 和 split 字段；
- 至少一种真实参数更新方式及其 checkpoint；
- 同域验证、跨域测试和至少一个完全留出的外部数据集评估；
- 同一套合成刺激；
- 逐层特征和物理时间轴；
- 线性 probe；
- 每层时间分辨率；
- 理论和实测有效感受野/上下文范围；
- 输出更新率；
- onset、tempo、phase、jitter、omission 评价；
- 离线与 causal 或伪流式比较；
- 计算量、内存和延迟记录。

不得预先把某层命名为“节律层”“语义层”“听觉皮层层”或“快速变化层”。层功能只能由独立 probe、混杂控制、跨条件泛化和因果消融共同支持。

### 5.5.5 TB001 的输入、输出和进入条件

**进入条件：**

- 与 TA001 对齐的刺激 schema 和 ground truth 可用；
- 至少两个训练数据源和一个外部评价数据源的版本、许可、访问与 manifest 核验完成；
- 模型可用性、可训练路径、许可证和资源核验完成；
- probe 切分、防泄漏和置换基线已预定义；
- 能把模型输出位置映射回物理时间。

**最低输入：**

- pure tone、AM、regular beat；
- onset/offset；
- phase shift、jitter 或 omission 中至少一种受控扰动；
- silence/noise 和 matched-random；
- 至少两个公开语音/音频数据源进入训练或分阶段微调；
- 至少一个独立数据源只用于外部评价，不参与模型选择。

**最低输出：**

- 传统基线、简单模型和预训练模型的结构化结果；
- 各层张量形状、时间分辨率和有效上下文；
- layer-wise probe；
- 时间扰动前后信息可读性；
- causal/伪流式结果；
- 参数量、内存、延迟、real-time factor；
- 每个数据源的采样权重、有效小时数、丢弃比例、标签映射和训练步数；
- checkpoint、优化器状态或参数高效训练权重，以及训练损失与验证曲线；
- leave-one-dataset-out、跨说话人和至少一种跨语言/跨域结果；
- 配置、种子、测试和失败记录。

**退出条件：**

- 逐层提取稳定且无明显时间轴错误；
- probe 不依赖相邻时间泄漏或标签捷径；
- 至少一个时间变量在层间呈现可重复的保留、增强或损失差异；
- 结果能与传统/简单基线比较；
- 离线与 causal/伪流式差异可解释；
- 至少两个独立数据源真实参与参数更新，且一个未参与训练的外部数据集用于泛化评价；
- 跨数据集结果超过预注册的单数据集训练、随机初始化或冻结特征 null 中至少一个强基线，同时报告失败域。

## 5.6 TB002 及以上的长期编号

| 编号 | 研究主题 | 对前序任务的依赖 |
|---|---|---|
| `TB001` | 公开数据核验、可训练基座与跨数据集最小闭环 | 数据/许可/资源、统一 manifest 和 probe 规范 |
| `TB002` | 逐层时间信息分析及模块删除、替换和消融 | TB001 形成跨数据集冻结 baseline |
| `TB003` | 增加快速变化监测通路 | TB002 定位到可干预的时间损失环节 |
| `TB004` | 快通路与慢通路融合 | TB003 证明快通路有独立信息贡献 |
| `TB005` | 自适应时间常数与动态采样 | TB004 或 TB002 提供多尺度强基线 |
| `TB006` | event-driven update 和状态重置 | 稳定事件 ground truth 与漏检保险 |
| `TB007` | 实时因果处理 | 前序结构在 causal/streaming 门禁下成立 |
| `TB008` | 跨模态适配接口与路线 C 交接 | TB007 或冻结的非流式模型；数据边界明确 |

## 5.7 TB002 的重点机制问题

TB002 应重点研究：

- 删除 pooling 是否恢复时间精度；
- stride 变化如何影响 onset 和 phase；
- context 增大是否改善全局节律但损害快速响应；
- attention 是否保留精确时间位置；
- recurrence 和 state-space 是否更适合连续状态；
- tokenization 是否造成时间边界损失；
- 多尺度分支是否优于单一感受野；
- 专门的高速变化监测通路是否能够弥补主干网络的迟滞；
- 高速通路是否只增加噪声敏感性；
- 如何在时间精度、内容识别和实时计算之间取得平衡。

所有消融至少建立参数匹配、计算匹配或延迟匹配中的一条主比较线，并同时报告其他两条是否改变结论。

# 6. 路线 C：真实神经信号表征与听觉—神经对齐

## 6.1 研究对象与对齐单元

路线 C 不把 EEG、MEG、fMRI、iEEG/ECoG、LFP 和 spike 当成同一层级。每个数据集必须分别记录测量模态、受试者、脑区/传感器、采样率、预处理、刺激、标签、时间同步和许可。最低对齐单元是同一刺激片段及其时间窗，而不是不同模型原始参数之间的逐元素对应。

## 6.2 路线 C 工作包

| 编号 | 名称 | 主要输入 | 主要输出 |
|---|---|---|---|
| `TC001` | 公开神经数据核验与语音—神经编码基线 | 冻结听觉基座、SparrKULee 或 MEG-MASC | 数据 manifest、时间对齐、encoding/decoding baseline |
| `TC002` | 跨被试与跨数据集神经表示 | 至少两个兼容神经数据源 | subject adapter、leave-subject/dataset-out 结果 |
| `TC003` | 语言/语义层级对齐 | Narratives、Brain Treebank 等 | layer/lag/ROI 对齐图与替代解释 |
| `TC004` | 情绪/韵律桥接 | 语音情绪数据与神经情绪数据 | 共同标签本体、弱/强配对边界 |
| `TC005` | 发音与运动相关表征 | speech-production 或 motor 数据 | 感知—发音—运动变量的可读性 |
| `TC006` | 表征干预与功能检验 | 冻结对齐模型和可操纵 latent | 干预结果、因果边界和 no-go |

## 6.3 路线 C 的最低证据梯度

1. 表征相似：RSA、CKA、CCA 或其他预注册相似性；
2. 预测对齐：听觉表示预测 held-out 神经响应，或神经表示读取声音/任务变量；
3. 泛化对齐：跨刺激、跨被试或跨数据集仍成立；
4. 功能/干预对齐：改变特定表征后，神经预测或下游输出按预注册方向改变。

第 1 级不能写成模型显式使用或脑区对应；第 2–3 级不能自动写成因果机制；只有第 4 级且排除混杂后才允许讨论有限功能作用。

# 7. 三阶段长期结构

## 7.1 “三阶段 × 三条路线”总矩阵

| 阶段 | 共同问题 | 路线 A：计算神经仿真 | 路线 B：可训练听觉基座 | 路线 C：真实神经与对齐 | 阶段共同产出与门槛 |
|---|---|---|---|---|---|
| **阶段一：数据、基线与信息观察** | 数据和基座是否足以承载后续对齐？ | 声音→发放率→spike；简化模型与经核实成熟模型对照 | 冻结公开数据组合；至少两数据源训练和一外部数据源评价；逐层表示、probe、资源测量 | 核验神经数据、同步和许可；建立至少一个语音→神经 encoding baseline | 可运行、可复现、时间轴正确；跨数据集训练真实发生；失败与边界明确 |
| **阶段二：扰动、消融与对齐定位** | 为什么某些信息被保留、丢失或只在特定神经尺度可预测？ | 改换能、适应、delay/jitter、noise、population 和 coupling | 数据消融、模块删除、stride/pooling/context、fast/slow pathway、参数与资源匹配 | layer×lag×sensor/ROI 对齐、跨被试与跨数据集复现、混杂控制 | 改动对象单一或可归因；结果跨种子/条件/被试稳定；存在可证伪机制假设 |
| **阶段三：调控与下游功能** | 能否有目的地改变中间表征并使下游输出按预期变化？ | 调节输入、spike、同步和 LFP proxy；检验 decoder/控制节点 | 建立强调时间变化的新算子；检验跨域、实时性和资源 Pareto | 干预声音或共享 latent；检验神经预测、任务读取和功能后果 | 不只局部相似；至少达到跨条件读取、泛化预测或因果干预中的预注册门槛 |

## 7.2 阶段一：建立可运行基线并观察信息变化

### 7.2.1 路线 A

**输入：** 统一合成刺激、外周近似参数、spike 随机种子。  
**过程：** 建立声音到发放率和 spike 的最小仿真；复现一个经过核实的历史模型或建立可解释简化模型；建立 raster、PSTH、ISI、vector strength 和 decoder。  
**输出：** 各载体的结构化表示、指标、图和 held-out 读取结果。  
**进入条件：** 刺激 ground truth 和时间轴通过自检。  
**完成条件：** 输入信息能从 spike 中稳定读取，且模型边界与随机性可说明。

### 7.2.2 路线 B

**输入：** LibriSpeech、Common Voice、MSP-Podcast/IEMOCAP 等经许可冻结的数据子集，传统特征、简单模型和经核实代表模型。  
**过程：** 统一 manifest；在至少两个数据源上进行真实参数更新；提取逐层表示；建立时间、内容和情绪/韵律 probe；记录有效上下文、因果性、延迟和资源。  
**输出：** checkpoint、训练曲线、数据采样账本、同域/跨域/留一数据集结果、layer-wise 信息曲线和资源表。  
**进入条件：** 数据/模型版本、许可、访问、隐藏层接口、训练配方和切分规范已核验。  
**完成条件：** 至少两个独立数据源参与训练，一个外部数据源保持未训练评价；结果相对强基线可解释且无明显泄漏。

### 7.2.3 路线 C

**输入：** 路线 B 冻结的听觉基座，以及 SparrKULee 或 MEG-MASC 中一个经核验的语音—神经配对数据集。  
**过程：** 重建刺激—神经时间映射，建立低容量线性 encoding/decoding baseline，并预注册 subject/stimulus split。  
**输出：** dataset manifest、同步检查、layer×lag 结果、跨被试结果和 null。  
**进入条件：** 路线 B 基座版本冻结；神经数据许可、同步和预处理可审计。  
**完成条件：** 至少一个 held-out 神经预测或匹配任务超过预注册 null，或者形成可解释 no-go。

阶段一不要求提出新模型，也不要求证明神经—网络同构。

## 7.3 阶段二：通过扰动、消融和结构修改理解机制

### 7.3.1 路线 A

改变：

- frequency channel；
- compression；
- adaptation；
- membrane time constant；
- refractory period；
- firing threshold；
- synaptic integration；
- fixed delay；
- delay jitter；
- connection noise；
- population size；
- synchrony；
- inhibition；
- coupling strength。

观察对 firing rate、spike timing、phase locking、population information、LFP proxy 和 downstream decoder 的影响。

**输入：** 阶段一冻结的基线与 decoder。  
**输出：** 参数—载体—信息—下游功能的敏感性矩阵。  
**进入条件：** 基线跨种子稳定，单一参数能独立操纵。  
**完成条件：** 至少一种信息损失可被具体机制解释，并有替代解释对照。

### 7.3.2 路线 B

进行：

- 模块删除和替换；
- stride 和 pooling 修改；
- context 修改；
- fast pathway 和 slow pathway；
- multi-rate update；
- event-driven update；
- gated fusion；
- adaptive sampling；
- auxiliary next-event prediction；
- causal buffering；
- 模块和参数量匹配消融。

**输入：** 阶段一冻结 baseline、训练预算和统一评价。  
**输出：** 模块因果贡献、质量—时间精度—资源 Pareto 和失败模式。  
**进入条件：** 至少一个 baseline 足以承载消融，测试集未被反复用于选择。  
**完成条件：** 结构效应不能由参数量、前端、训练目标或 look-ahead 单独解释。

### 7.3.3 路线 C

比较不同听觉模型层、神经模态、sensor/ROI、时间 lag、任务变量和对齐损失；至少加入声学包络、说话人、刺激身份、数据集身份和时间错配对照。跨数据集训练时分别报告共享参数、数据集 adapter 和完全独立模型，不能把数据集身份泄漏当成共同神经表征。

## 7.4 阶段三：研究调控和人工结构对下游功能的影响

### 7.4.1 路线 A

- 对输入进行调节；
- 对 spike 模式进行人工修改；
- 对 population synchrony 进行调节；
- 对 LFP proxy 状态或振荡结构进行调节；
- 将自然产生的中间状态替换为人工构造状态；
- 观察下游 decoder 或控制节点是否仍能正确读取；
- 区分局部相似、跨条件解码和下游功能保持。

**进入条件：** 自然状态、人工状态和下游读取接口均稳定。  
**输出：** 人工干预对下游功能的因果结果和失效范围。  
**完成条件：** 变化方向与预注册假设一致，或形成明确阴性结论；不以局部波形相似替代功能。

### 7.4.2 路线 B

- 建立更强调时间变化的新算子或模型；
- 比较新结构与现有模型；
- 检查改进是否来自结构而非参数量；
- 检查快速通路是否真正提高变化检测；
- 检查慢速通路是否提供长期上下文；
- 检查新模型是否适用于实时输入；
- 探索在声音、LFP、EEG 或其他连续时序信号中的迁移。

**进入条件：** 阶段二已定位明确损失机制或资源瓶颈。  
**输出：** 公平基线下的新结构证据、因果消融、流式结果和迁移边界。  
**完成条件：** 至少在一个预注册机制维度上优于强基线或形成更优 Pareto；允许“没有新结构值得继续”的结论。

### 7.4.3 路线 C

对声音属性或共享 latent 进行受控干预，检验神经预测和下游任务是否产生方向一致变化。参数互预测只能在共享架构、参数可辨识和独立功能验证成立后作为探索性 H，不作为路线 C 的默认方法。

## 7.5 阶段依赖原则

1. 阶段二依赖阶段一的冻结基线；没有 baseline 不进入结构解释。
2. 阶段三依赖阶段二定位到可操纵机制；没有机制证据不宣称有目的的功能调控。
3. 路线 C 的声音侧输入依赖路线 B 冻结的模型、前端、时间轴和 checkpoint；未经批准不得边对齐边改变基座。
4. 路线 A 可独立推进；路线 B 是路线 C 的默认前置依赖。
5. 每条路线内部的进入条件由证据而不是日期触发。
6. 某阶段 no-go 后可以回退、缩小问题或更换实现，但必须保留原失败记录。

# 8. 近期最小闭环

## 8.1 最小闭环的共同定义

近期不完成整个三阶段。按人工当前优先级，先建立路线 B 的数据—训练—外部评价闭环；路线 A 可独立排期，路线 C 在路线 B 基座冻结后启动。任何一项只有形成以下链条才算闭环：

```text
输入
→ 模型或仿真
→ 中间信息
→ 下游读取
→ 参数扰动
→ 输出变化
```

只生成图、只运行模型、只得到分类准确率、只提取中间层或只改变参数，都不单独构成闭环。

## 8.2 TA001：听神经 spike 仿真最低交付

1. 可控声音生成；
2. 频率通道；
3. 发放率；
4. spike train；
5. spike raster；
6. PSTH；
7. phase locking；
8. 不同频率和强度对照；
9. 一个时间参数扰动；
10. 从 spike 中读取至少一种输入属性；
11. 单元测试；
12. 可复现配置和结果。

建议最低的读取任务优先选择纯音频率、强度档、AM rate 或节拍 phase 中的一项。读取器应保持简单，并用 held-out 刺激或随机种子验证。

## 8.3 TB001：公开数据、可训练基座与跨数据集训练最低交付

1. 公开数据登记表、来源、版本、许可和访问状态；
2. 至少两个训练数据源和一个外部评价数据源；
3. 统一 manifest、标签本体、采样策略与防泄漏 split；
4. 传统基线和一个简单可训练模型；
5. 一个代表性、公开、可训练的语音基座；
6. 真实参数更新、checkpoint、训练曲线和失败运行；
7. 同域、跨域和 leave-one-dataset-out 评价；
8. 逐层表征及声学/音系/语言/情绪或时间 probe；
9. 一个时间结构扰动；
10. causal 或伪流式测试；
11. 延迟、显存、训练时间和存储记录；
12. 单元测试与可复现配置。

TB001 的首要风险是前端或下采样已经使目标变量不可用。若某模型输入端不保留 phase，应把它作为系统属性报告，而不是用更复杂 probe 掩盖。

## 8.4 TC001：首个语音—神经对齐最低交付

1. 一个经核验的公开语音—EEG或语音—MEG数据集；
2. 路线 B 冻结 checkpoint；
3. 刺激—神经时间同步自检；
4. 声学包络等传统基线；
5. 低容量 encoding/decoding 或 match/mismatch baseline；
6. held-out subject/stimulus 评价；
7. 时间错配、标签置换和数据集身份对照；
8. layer×lag 结果与结论边界。

## 8.5 三项任务的独立性与汇合点

TA001、TB001 和 TC001：

- 不要求同一时间完成；
- 不共享模型实现；
- 不互相借用“生物合理”或“模型先进”作为验收理由；
- 必须共享刺激定义、事件时间和至少一组时间变量；
- TC001 必须使用冻结的 TB001 checkpoint，不得用神经测试集反向选择声音基座；
- 在各自闭环完成后，才能比较同一输入变量在 spike、人工模型层和真实神经记录中的可读性与损失。

## 8.6 最小闭环不包含的事项

近期最小闭环不包含：

- 完整听觉通路；
- 真实临床 LFP 仿真；
- 从随机初始化重训超大基础模型；
- 新型基础模型的正式提出；
- 患者刺激实验；
- 自然与人工输入功能等价结论；
- TA002/TB002/TC002 及以上任务书。

# 10. 统一输入和评价

## 10.1 统一输入计划

| 输入维度 | 最小操纵 | 主要回答 |
|---|---|---|
| pure tone frequency | 多个可分频率，覆盖通道中心附近和通道间 | 频率选择与通道分离 |
| intensity | 多档幅度/声级代理 | 动态范围、压缩和饱和 |
| onset / offset | 独立操纵起止和持续时间 | 瞬态、持续与恢复 |
| AM | 调制率、深度、相位 | 包络跟随与调制传递 |
| regular beat / tempo | 等时事件和不同 rate | 节拍率、周期状态 |
| jitter | 局部间隔扰动 | 快速时间精度与阈值 |
| phase shift | 在固定 rate 下改变相位 | 相位可读性和恢复 |
| omission | 可预测时刻省略事件 | 事件检测与预测状态分离 |
| rate change | 序列中途改变 rate | 适应、切换延迟和状态更新 |
| matched-random | 匹配事件数/能量的随机序列 | 排除总能量与事件数捷径 |
| silence | 无输入基线 | 自发率、假阳性与状态漂移 |
| noise | 多 SNR 或背景类型 | 鲁棒性和增益控制 |
| 真实语音/环境声 | 少量、许可明确的泛化输入 | 检查合成任务之外的迁移 |

## 10.2 统一 ground truth

所有合成输入至少保存：

- `stimulus_id` 和生成器版本；
- waveform；
- sample rate；
- duration；
- event onset；
- event offset；
- frequency；
- intensity 及其校准状态；
- modulation rate/depth/phase；
- beat rate 和 beat phase；
- omission position；
- jitter magnitude 与具体实现；
- rate change time；
- noise 类型与 SNR；
- random seed；
- split 标识；
- 生成配置和校验摘要。

对没有声能的 omission，要保存 expected event time，不能伪造一个实际 onset。

## 10.3 数据切分和防泄漏

1. 训练、验证和测试使用独立刺激 seed。
2. 需要按 stimulus、block、session 或 subject 分组时，不随机切分相邻时间点。
3. probe 的层选择、lag、正则化和阈值只在训练/验证折选择。
4. 时间卷积、滤波和窗口不能跨越 split 边界。
5. matched-random、silence、time-shift 和 label permutation 作为必要负控制。
6. 若模型前端包含未来信息，不能把结果标记为 causal。

公开多数据集训练还必须使用：

- `dataset_id`、`source_id`、`speaker_id`、`subject_id`、`stimulus_id` 和衍生关系分组；
- 同一原始说话人、故事、电影、播客、书籍章节或派生音频不得跨 train/test；
- 数据集均衡采样或显式采样权重，报告每个数据源真实贡献；
- 至少一个完整数据集仅用于外部评价；
- 神经数据按受试者和刺激双重 held-out，禁止将相邻时间窗随机拆入不同集合。

## 10.4 路线 A 指标

- firing rate；
- PSTH；
- spike count；
- first-spike latency；
- inter-spike interval；
- vector strength；
- synchrony；
- mutual information 或其他信息指标；
- population decoding；
- LFP proxy power；
- phase；
- cross-frequency coupling；
- downstream decoder。

信息指标不能替代 held-out decoding。连续高维变量的 mutual information 估计可能不稳定，应同时报告可复现的 decoder、置换 null 和跨条件结果。

## 10.5 路线 B 指标

- onset F1；
- onset MAE；
- tempo MAE；
- phase circular error；
- omission AUROC；
- next-event MAE；
- layer-wise probe；
- representation similarity；
- streaming latency；
- real-time factor；
- memory；
- parameter count；
- causality；
- robustness。
- 同域与外域指标差、leave-one-dataset-out、最差数据集性能和数据源均衡宏平均；
- ASR/音系、说话人、语言、情绪/韵律和时间变量的分任务结果。

representation similarity 需要维度匹配、time-shift 和标签置换控制；相似度高不代表功能等价。

## 10.6 路线 C 指标

- encoding：held-out 神经响应 correlation、\(R^2\) 或预注册预测指标；
- decoding/matching：声音—神经匹配、检索或任务变量读取；
- 对齐：RSA/CKA/CCA 等表征相似性，但与预测性能分开报告；
- 泛化：leave-subject-out、leave-stimulus-out、leave-dataset-out；
- 时空定位：layer×lag×sensor/ROI，并控制多重比较；
- null：时间错配、标签置换、随机模型、声学包络和数据集身份 baseline。

## 10.7 共同评价原则

必须区分：

1. **输入是否被检测到**：系统对刺激存在响应；
2. **中间状态是否包含信息**：probe 能读取变量；
3. **信息是否能被 decoder 读取**：在 held-out 条件下可用；
4. **是否跨条件泛化**：频率、强度、噪声、rate、seed、说话人、受试者或数据源变化后仍成立；
5. **下游功能是否保持**：中间状态实际支持目标输出；
6. **局部状态相似是否对应功能相似**：需要跨条件 decoder 或因果干预验证。

证据强度遵循：

```text
response
< selectivity/tuning
< held-out encoding/decoding
< cross-condition generalization
< causal contribution
< downstream functional preservation
```

## 10.8 公平性、统计和可复现性

- 共享前端比较与原生端到端系统比较分开；
- 参数匹配、计算匹配和延迟匹配分开报告；
- 同数据、同增强、同训练预算、同因果约束、同输出时间分辨率；
- 多随机种子，优先成对比较；
- 报告 effect size、置信区间和逐条件曲线；
- 预先定义主要指标和 no-go 条件；
- 阴性、失败和不稳定结果与阳性结果同等留档；
- 不以一次成功运行证明复现。

# 12. 项目边界

## 12.1 近期不做或不能直接声称

- 不在近期完整复刻从耳蜗到高级听觉皮层的所有生物细节；
- 不将简单 LIF 直接解释为真实听神经全部机制；
- 不把由 spike 或群体活动合成的 LFP proxy 直接当作真实临床 LFP；
- 不将深度模型某一层直接等同于某个脑区；
- 不以最终分类准确率代替中间信息分析；
- 不在没有 baseline 的情况下直接提出新模型；
- 不以参数量增加作为结构创新；
- 不以一次成功运行证明模型复现；
- 不以局部表征相关证明自然输入和人工输入功能等价；
- 不要求近期从随机初始化重训超大基础模型，但 TB001 必须发生真实参数更新并保存 checkpoint；
- 不把不同模型的原始参数逐元素互预测默认视为表征对齐；
- 不预设某一种现代模型必然优于所有其他模型；
- 不隐藏阴性结果和失败参数。

## 12.2 生物解释边界

1. “耳蜗样”“毛细胞样”“听神经样”均表示明确近似，不表示解剖复刻。
2. spike generator 的统计性质必须说明；Poisson、renewal、LIF 和成熟外周模型不可混称。
3. population synchrony 可能来自共同输入，不能自动解释为突触耦合。
4. LFP 主要与群体跨膜/突触电流和几何传导有关；简单 spike 卷积只能称为 proxy。
5. cross-frequency coupling 需排除滤波、波形形状和共同事件诱发的伪耦合。
6. STN 相关材料为长期脑机接口背景；路线 A 初期不是 STN 生理复现。

## 12.3 AI 解释边界

1. 前端已丢失的信息不能归咎于后续时序算子。
2. hidden state 可读不等于主任务实际使用。
3. 长 context window 不等于长程信息无损保存。
4. causal 不等于低延迟 streaming。
5. 模型名称或作者宣传不构成“优于 Transformer”的证据。
6. 结构、训练目标、数据规模和预算必须分开归因。

## 12.4 临床和安全边界

本项目当前是算法研究平台，不是医疗软件，不控制 DBS，也不定义患者刺激参数。未来如连接真实患者数据或人工刺激研究，必须另行满足伦理、设备安全、同步、隐私、数据授权和临床停止规则；这些内容不能由仿真成功自动授权。

# 13. 里程碑与决策门槛

## 13.1 总体决策原则

每一阶段应使用“证据门槛”而不是“完成了多少代码”判断是否继续。门槛至少包含：

- 正确性：时间轴、单位、状态和随机性正确；
- 可读性：held-out decoder/probe 超过置换或机会水平；
- 稳定性：跨 seed、刺激或重复稳定；
- 可解释性：结果与操纵方向一致，替代解释被控制；
- 可复现性：配置、代码、结果和测试可重新生成；
- 资源可行性：运行时间、内存、延迟处于实际范围；
- 边界清楚：阴性和不确定性不被隐藏。

具体数值阈值应在对应任务开始前依据强 baseline、随机种子方差和应用容忍度预注册；本总纲不虚构普适阈值。

## 13.2 路线 A 的近期、中期和长期里程碑

| 时段 | 里程碑 | Go 条件 | No-go / 转向条件 |
|---|---|---|---|
| 近期 | TA001 完成声音→rate→spike→decoder→扰动闭环 | frequency/intensity/time 变化方向合理；至少一种属性可 held-out 读取；跨 seed 稳定 | spike 仅反映实现伪影；时间轴/单位无法校验；简化模型无可读信息 |
| 中期 | TA002–TA004 建立群体、宏观 proxy 和节点传递 | 群体相对单单元提供可量化信息/鲁棒优势；proxy 生成假设明确；跨节点变换可追踪 | 增加群体或层级只增加复杂度；proxy 对生成规则极端敏感且无验证路径 |
| 长期 | TA005–TA008 建立扰动、decoder、自然/人工比较和闭环 | 人工干预引起预期下游变化；跨条件 decoder 或功能保持成立 | 只有局部相似、无下游读取；刺激状态不可区分于共同能量/伪影；闭环不稳定 |

### 13.2.1 路线 A 的停止条件

- 连续多个合理模型和随机种子下，目标信息均无法从最早载体读出；
- 结果主要由 bin width、滤波边缘、随机数实现或标签泄漏决定；
- 生理参数无法获得或模型不可辨识，导致多个相反机制同样解释结果；
- LFP proxy 无法建立可审计 forward assumption；
- 下游功能不随中间状态的目标性变化而变化。

### 13.2.2 路线 A 的转向条件

- spike 生成过早成为瓶颈时，先回退到 instantaneous rate 闭环；
- 单通道不足时扩展群体，但不先扩展完整核团；
- 成熟模型许可/资源不可用时，保留简化基线并更换可核验模型；
- LFP proxy 不可靠时，先研究 population state，不强行进入 TA003；
- 自然/人工比较只达到局部相似时，收缩结论并加强共同 decoder/功能测试。

## 13.3 路线 B 的近期、中期和长期里程碑

| 时段 | 里程碑 | Go 条件 | No-go / 转向条件 |
|---|---|---|---|
| 近期 | TB001 完成公开数据核验、至少两数据源训练和外部数据集评价 | checkpoint 与训练账本可重建；跨域结果超过预注册强基线；中间层与时间轴可提取 | 数据/模型许可不符；只有单数据集训练；外域性能崩溃且无法解释；资源超预算 |
| 中期 | TB002–TB006 定位数据与模块作用并检验快慢/事件机制 | 至少一个数据或结构改动在机制指标、跨域泛化或资源 Pareto 上稳定优于匹配 baseline | 改进由数据量、参数、前端、look-ahead 或预算解释；高速通路只增加噪声 |
| 长期 | TB007–TB008 达到因果流式并形成路线 C 可复用接口 | 零/固定 look-ahead 下仍有优势；延迟与状态可控；跨模态 adapter 无需改写主干 | 仅离线有效；实际延迟/内存不可接受；每个神经数据集均需完全重训主干 |

### 13.3.1 路线 B 的停止条件

- 强 baseline 在相同前端和资源下已经达到机制上限；
- 所谓新结构优势在参数、FLOP 或延迟匹配后消失；
- probe 结果对切分、维度或正则高度不稳定；
- 局部时间改进以不可接受的内容识别、噪声鲁棒或实时成本为代价；
- 当前数据与任务不能区分提出的机制假设。
- 多数据集训练只学到数据集或说话人身份，未改善外部泛化；
- 数据许可或来源不能支持联合训练和结果发布。

### 13.3.2 路线 B 的转向条件

- 大型模型资源不足时，转向 Base/Small、adapter、LoRA、冻结部分前端或梯度累积，不从随机初始化重训超大模型；
- 数据规模超过预算时，采用可复现分层抽样，但仍保留至少两个独立训练数据源和一个外部评价集；
- 预训练模型无法流式时，保留其离线对照并增加 causal/伪流式 baseline；
- phase 在前端已丢失时，转向前端消融或选择可保留复数/波形信息的系统；
- 新架构无总体优势但在某个机制任务有效时，收缩为专用算子研究；
- 所有候选不优于强 baseline 时，保留阴性结论并停止扩张结构。

## 13.4 路线 C 的近期、中期和长期里程碑

| 时间层级 | 目标 | Go 候选 | No-go / 转向候选 |
|---|---|---|---|
| 近期 | TC001 跑通一个公开语音—EEG/MEG encoding/decoding baseline | 时间同步可重建；held-out 预测超过 null；传统声学与深层表征可公平比较 | 许可/同步不可审计；结果由刺激身份、相邻窗口或说话人泄漏解释 |
| 中期 | TC002–TC005 建立跨被试、跨数据集及语言/情绪/运动变量对齐 | 至少一个结果跨被试与外部数据复现；失败模态明确 | 仅单受试者/单数据集成立；adapter 只识别数据集身份 |
| 长期 | TC006 进行表征干预和功能检验 | 干预方向与神经预测或任务输出一致，并通过替代解释对照 | 只有静态相似，无预测增益或功能后果 |

## 13.5 路线 A 进入 TA002 的条件

- TA001 能稳定生成合理 spike；
- 输入属性可以从 spike 中读取；
- 时间扰动产生可解释变化；
- 结果跨随机种子稳定；
- 模型边界清楚；
- 测试和图形可复现。

此外，需确认 TA002 研究的问题确实需要群体，而不是用更多单元掩盖 TA001 的单元模型缺陷。

## 13.6 路线 B 进入 TB002 的条件

- 至少一个 baseline 和一个代表模型跑通；
- 中间层可以稳定提取；
- 时间 probe 不存在明显泄漏；
- 模型层之间出现可解释差异；
- 流式或伪流式评估可运行；
- baseline 足以支持结构消融。
- 至少两个独立数据源实际参与参数更新，并保存每个数据源的训练步数和采样权重；
- 至少一个完整外部数据集从训练与模型选择中隔离；
- 跨数据集结果已与单数据集训练、冻结特征或随机初始化中的至少一个强基线比较。

此外，TB002 的首个消融必须能指向 TB001 中已经观察到的具体时间信息变化。

## 13.7 路线 C 进入 TC002 的条件

- TB001 checkpoint、前端、逐层时间轴和数据使用范围已经冻结；
- TC001 的神经数据、刺激、同步、预处理和 split 可以重建；
- 至少一个 held-out 结果超过预注册 null，或形成明确 no-go；
- 声学包络、时间错配、随机模型、说话人/受试者和数据集身份等主要混杂已检查；
- 未把参数映射、表征相似或 probe 可读夸大为机制同一。

## 13.8 阴性结果的决策价值

以下结果均可作为有效阶段结论：

- 简化 spike 模型无法同时保持 rate 与 timing；
- 成熟模型没有比简化模型提供额外可读信息；
- 某预训练模型在内容任务强，但局部 phase/omission 信息很早丢失；
- 删除 pooling 提高时间精度但显著损害噪声鲁棒；
- fast pathway 没有独立贡献；
- 自然状态与人工状态局部相似但不能跨条件读取；
- 所有候选均不优于强 baseline。

项目是否继续由这些结果是否缩小了机制不确定性决定，不由结果是否“阳性”决定。

# 14. 三条路线的汇合方式

## 14.1 汇合条件

三条路线汇合前必须满足：

- 使用相同或可对齐的声音刺激；
- 能够定义共同的时间信息变量；
- 能够比较不同系统的中间信息；
- 能够建立共同下游 decoder；
- 能够进行输入或中间状态扰动；
- 能够区分局部相似和功能相似。
- 路线 B 的听觉基座版本、训练数据、checkpoint 和逐层时间轴已经冻结；
- 路线 C 的神经数据同步、subject/stimulus split 和 null 可以重建。

TB001 和 TC001 未各自闭环前，不开展“神经表示与模型层同构”的主张；TA001 未闭环时，也不得用路线 A 的仿真层级解释路线 C 的真实神经结果。

## 14.2 共同比较坐标

| 共同变量 | 路线 A 表示 | 路线 B 表示 | 路线 C 表示 | 共同问题 |
|---|---|---|---|---|
| frequency | 通道 rate/spike pattern | 前端/层表示 | sensor/ROI response | 哪个阶段仍可区分频率 |
| intensity | rate-level、spike count | 幅度/归一化后表示 | ERP/field/BOLD amplitude | 压缩后是否仍可读 |
| onset | first-spike/PSTH | frame/hidden activation | evoked response/lag | 事件时间误差多大 |
| AM/tempo | spike phase/rate modulation | 层级 temporal state | entrainment/temporal response | 调制率在哪一层丢失 |
| phase | vector strength/population phase | phase-aware 或隐藏表示 | phase consistency | phase 是否可跨条件读取 |
| jitter | spike timing deviation | fast-state/probe | response latency variation | 最小可检测扰动与噪声代价 |
| omission | expected-time population state | predictive/context state | omission-locked response | 无实际声能时是否形成预期响应 |
| language/emotion | 不默认具备 | 音系/语义/韵律层表示 | neural decoder/ROI pattern | 能否跨刺激和被试预测 |

## 14.3 三类汇合实验

1. **共同 probe**：对三条路线的中间表示使用相同标签、切分和低容量 decoder，比较可读性而非维度大小。
2. **共同扰动**：对输入施加相同 jitter、phase shift、omission、noise 或 rate change，比较信息损失曲线。
3. **功能替换**：在明确接口下，用人工构造的中间表示替换原表示，观察共同下游 decoder 是否保持功能。

表示维度、采样率和噪声不同，需要维度匹配、时间对齐和容量控制，不能直接比较原始相关系数。

## 14.4 从局部相似到功能相似的证据梯度

汇合后的结论按强度分级：

1. 相同输入引起局部平均响应相似；
2. 时间、相位、频谱或状态轨迹相似；
3. 自然条件训练的 decoder 能读取人工条件，反向亦然；
4. 类别/连续变量结构在 held-out 输入中相似；
5. 下游节点对两类状态具有相似读出；
6. 扰动两类状态产生相同方向的功能后果；
7. 排除能量、维度、共同输入、任务标签和时间自相关等替代解释。

只有达到第 3 级及以上，才可讨论跨条件功能泛化；只有达到第 5–6 级，才可讨论较强的功能相似。即使达到这些级别，也不自动证明生物机制相同。

# 15. 第一批建议启动顺序

## 15.1 顺序原则

第一批工作按依赖而非日历安排：

1. **先冻结公开数据登记表**：确认数据版本、规模、来源、许可、访问方式、标签、语言/域和完整性检查方法。
2. **再冻结模型与资源**：以 wav2vec 2.0 作为经典可训练基线，WavLM 作为候选主干，确认精确版本、训练方式、逐层接口和资源预算。
3. **优先创建 TB001 任务书**：至少两个独立数据源进入训练，一个完整外部数据集只用于评价；本条确定优先级但不自动授权执行。
4. **先做最低复杂度训练闭环**：先跑通短时、Base/Small 或参数高效训练，再按证据扩大有效小时数和任务头。
5. **完成跨数据集 go/no-go**：核查 checkpoint、训练曲线、数据采样账本和外域泛化，失败数据域同样保留。
6. **冻结声音侧基座后创建 TC001**：首选 SparrKULee 或 MEG-MASC，先做低容量 encoding/decoding 与严格 null。
7. **TA001 独立排期**：计算神经仿真不作为 TB001 的前置条件，但仍为长期机制比较保留。
8. **满足三路线汇合条件后再建立共同 decoder**：不提前做脑区—模型层命名或原始参数互预测。

## 15.2 第一批共享定义的优先级

建议最先冻结：

- pure tone frequency × intensity；
- onset/持续刺激；
- 一个 AM 或 regular beat；
- 一个 phase shift/jitter/omission 扰动；
- silence、noise、matched-random；
- event onset、expected onset 和 physical time；
- 随机种子和 split 规则；
- 输出时间分辨率和延迟的记录方式。
- `dataset_id/source_id/speaker_id/subject_id/stimulus_id` 与衍生关系；
- 训练数据采样权重、外部数据集隔离和标签本体映射；
- 模型 checkpoint、优化器状态、训练曲线和数据使用账本。

这些定义是 TA001、TB001 和 TC001 的共同基础，但不是新的正式任务书。

## 15.3 第一批审查点

- **审查点 D0**：数据来源、规模、版本、许可和访问是否可审计；
- **审查点 B0**：统一 manifest、split 和训练配方是否正确；
- **审查点 A1**：rate/spike 是否合理、可读、可复现；
- **审查点 B1**：至少两数据源真实训练是否完成，外部泛化、逐层输出、时间轴和 probe 是否可信；
- **审查点 C0/C1**：神经数据同步是否可重建，held-out encoding/decoding 是否超过严格 null；
- **审查点 ABC1**：至少一个共同变量能否使用相同 decoder 规范比较；
- **审查点 2**：是否有足够证据创建 TA002、TB002 或 TC002 的具体任务书。

未通过审查点时，修正当前闭环或记录 no-go，不自动扩大范围。

| HuBERT | 经典自监督语音候选 | 官方当前训练入口、精确版本、许可、资源和与 wav2vec 2.0 的增量价值 |
| Whisper encoder | 公开候选，未列为首个主干 | 官方权重和许可证、encoder 层接口、时间分辨率、离线/伪流式边界、资源 |
| BEATs / AudioMAE / MERT | BEATs 暂列通用音频对照；其余为后续候选 | 官方仓库/模型卡、权重可得性、许可证、逐层时间输出、前端和资源 |
| Conformer/Transformer 基线 | 架构级候选 | 具体实现、causal 版本、look-ahead、参数与训练预算 |
| state-space 模型 | 架构级候选 | 稳定官方实现、精确版本、音频适配、隐藏状态接口、流式执行和硬件 kernel |
| 其他公开模型 | 未冻结 | 原始论文、官方实现、模型卡、许可、可复现 checkpoint、逐层与流式能力 |

选择代表模型前，必须把“仍可下载、可提取中间层、可流式、是否需要 GPU、许可证是否允许”逐项记录。无法确认的候选保留“待核验”，不进入冻结 baseline。

## 16.4 数据、硬件和资源

- TB001 的目标有效小时数、每个数据源比例和训练步数待资源审计后预注册；
- 当前可用 CPU、GPU、显存、内存和磁盘预算待确认；
- 是否允许缓存大型模型权重、其存放位置和备份策略待确认；
- 语音/音频候选池已确认包括 LibriSpeech、Libri-Light、Common Voice、MSP-Podcast 和 IEMOCAP；精确版本、子集、访问与联合训练许可仍待任务级确认；
- 真实神经候选池已确认包括 SparrKULee、MEG-MASC、Narratives 和 Brain Treebank；精确版本、同步、访问、隐私与联合分析边界仍待任务级确认；
- 当前项目是否需要与上级 STN 刺激 manifest 对齐，待跨项目审核。

## 16.5 科学与方法学问题

- 简化外周模型的最低生理约束应包括哪些：压缩、适应、不应期、不同自发率纤维是否都需要；
- TA001 首个主要 decoder 读取 frequency、intensity、AM rate 还是 phase；
- phase locking 的目标频率范围和统计检验如何按模型条件预注册；
- LFP proxy 使用突触电流、膜电流还是群体 spike proxy，何时才值得进入 TA003；
- TB001 暂以 wav2vec 2.0 作为经典基线、WavLM 作为候选主干、BEATs 作为通用音频对照；最终精确版本由资源与许可门禁决定；
- LibriSpeech、Common Voice 与 MSP-Podcast 的统一采样、标签本体和数据权重如何预注册；
- 简单可训练 baseline 是否统一使用 causal TCN、GRU 或两者之一；
- causal 与伪流式的首轮 look-ahead/chunk 条件如何定义；
- probe 的维度匹配、时间 lag 和多重比较如何冻结；
- 路线汇合时选择哪个共同变量作为第一项功能比较。

## 16.6 创建后续任务书前的最低确认

未来只有在以下问题得到明确答案后，才创建优先任务 TB001 的具体任务书：

1. 至少两个训练数据源和一个外部评价数据源的精确版本、许可、访问与有效规模；
2. 统一 manifest、标签本体、数据采样权重和防泄漏 split；
3. wav2vec 2.0 基线及 WavLM 候选主干的精确代码、checkpoint、训练接口和许可；
4. 当前 GPU/CPU、显存、内存、磁盘和允许运行时间；
5. 训练方式是继续自监督、全量微调还是参数高效训练，以及真实参数更新的最低范围；
6. 同域、跨域、leave-one-dataset-out 指标、null、seed 和 go/no-go；
7. checkpoint、失败运行、数据使用账本和回滚/保留规则；
8. 下载、缓存和大体积数据存储的人工授权范围。

本总纲到此只完成长期研究结构，不代表上述待核验项已解决，也不授权自动进入实现、实验或 Agent 工作流。
