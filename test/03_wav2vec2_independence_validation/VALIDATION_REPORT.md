## 全新环境执行链

只使用该文档时，执行顺序为：

```text
发送任务规划 Prompt
→ 人类批准计划和音频方式
→ 发送启动 Prompt
→ 执行者从零建立环境、代码、实验、页面和交付包
→ 按阶段使用审核或返工 Prompt
→ 使用“全新环境交付复核” Prompt
→ 使用“最终验收并停止” Prompt
```

执行环境仍需具备合法文件写入权限、可用 Python、足够计算与磁盘资源，并能取得模型和输入音频。规划 Prompt 会在这些条件不足时先报告阻塞，不会把缺失资源伪装为实验结果。
