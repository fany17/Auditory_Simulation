## 被替换的草稿与理由

初稿的8个相邻64Hz点仅约125ms，不覆盖所需6秒。将完整历史全部平均成8维也抹去时序。后续12个半秒段回到旧 round01/warm 的0.5秒摘要瓶颈，且 H/P 采用不同分辨率。均未正式批准或拟合；不能将这些草稿当成已跑失败实验，也不能把它们计为候选搜索结果。

本版固定96个有序4点箱，覆盖全部384点。4点矩形平均是明确的信息压缩，不能声称无损或理想抗混叠；它避免先压成单个全段均值，不保证足够或有效。本轮只实现这一版，不建立12/96/384网格。

## 输入与当前对照

- 冻结原强 FT+Ccap。按既有正 Hann 权重融合原 latent，得唯一时间坐标 g(t)∈R8；锚点为原完整物理预测 b(t)。当前 query 始终是 g(t)。
- H：按升序取 g[t−288−383 : t−288+1] 共384点；每连续4点均值得96×8。完整六秒**特征**支持由全窗双向encoder产生，原始EEG支持更长，必须另列上下界。
- P：相同384个物理坐标、相同4点分箱，但输入是冻结 b(u)，得96×1。不给真实过去目标，不能称完整DECAF复现。
- C：取对当前物理点有正Hann贡献的两个原 latent 窗口，各192×8；每窗单独按4点平均成48×8，按前窗、后窗拼成96×8。若只有一个正贡献窗，两个slot均使用此合法窗；绝不借用零贡献或record外窗口。C原始EEG支持与 g(t)/b(t)已获准的当前并集一致。
- C的重复物理片段与两次窗口编码不是额外独立观测。C/H同维同网络，但有效内容、依赖和信息量不同，不声称等有效容量。
- Older 为同长度384点、lag960；保持 g(t)、其当前码、锚点、权重和评分坐标不变，仅替换 H/P 历史。near/older原始支持是否不相交由实际正权重builder检验，不只看特征坐标。
- 共同活动起点 t=1344。此前全部保持原锚点；全记录/原评分mask保留，不能删除冷启动或尾段。该起点源于历史可用性，未看新评分。

## 唯一网络

```
q = GELU(Linear(8,32)(g_norm(t)))
c = Linear(64,32)(GELU(Linear(D,64)(context_norm)))
h = GELU(Linear(32,32)(q * (1 + tanh(c))))
delta(t) = Linear(32,1)(h)
prediction(t) = b(t) + delta(t)
```

H/C 的 D=768，P 的 D=96。最后层 weight/bias 零初始化，其他层按共同seed规则初始化；no dropout、无跨batch运行统计。实际默认参数计数应为 H/C=52,673、P=9,665。P少输入参数是本征差异，单列而非复制/补零制造名义匹配。同hidden宽度不是全部容量等同。

当前 query 的统计与各角色 context 的统计只用原TRAIN活动点、等物理点计算；按实际路径冻结具体dtype/方差floor。Older沿用near TRAIN统计，不重拟合。固定Ccap原统计与系数保留；不是修改上游预处理。所有当前/历史点属于本record。

残差是每个物理点唯一标量；不生成独立192输出bias，不再通过多窗口残差相消。该参数化仍有一般神经网络冗余，也不证明比原网络更优。
