## 2. 精确公共物理点、固定边界和目标

窗口长192、stride96，w=原np.hanning(192)。对同记录物理点t，α_it=w(t−96i)/Σ_j w(t−96j)，只使用原完整记录中覆盖t的窗口，和D8评分相同；不跨记录，不对60秒块重置窗口或重复边缘目标。

每记录i<4始终固定p_i=P_FT*，i≥4的p_i=q_i+x_i B+b，其中q_i=P_FT*，x_i为D8同坐标Z1536/P192/Z平方1536，B/b初始化为D8 Ccap。**计算融合时保留首4个固定窗口的真实贡献**，不重新归一化成只含可学习窗口，也不去掉第一可学习窗的固定前邻居。

共同训练集合A是“原Hann有覆盖，且至少一个i≥4窗口以正α参与”的物理点。Hann两个零端点不作为正贡献；固定窗口独占、没有参数梯度的早期点不进入两臂分母。第一可学习窗开始于384，A从385起，延伸到最后完整窗口倒数第二点；原未覆盖尾部不填充。对n窗记录，|A|=(n−4)×96+94。

metadata实际计数：426记录/70人，252454总窗、250750可学习窗，**T=24112044个唯一物理目标点**。正Hann贡献47682544项，其中47642500项来自可学习窗，40044项来自首4窗中的固定边界上下文。上述计数尚待实现时根据原Hann权重实际构造核对，不冒称已读取真实目标数值。

共同y_t使用原TRAIN envelope缓存的float32目标再转float64；仅在2203核对相邻缓存窗的重复物理标签完全一致，以及与原record目标转float32一致，才构造唯一物理轴。相同真实目标在两臂均按物理点一次计权；W的多贡献权重之和为1。其验证评分继续使用既定原float64连续target/mask，并披露训练float32继承约定，不因成绩改target。

## 3. 两个目标与统一window MSE的区别

定义p̄_t=Σ_i α_it p_i(t)，固定正则λ̄=.01/192=5.208333333333334e−5。自由B仅含可学习输出列，截距不惩罚。两个目标为：

```
J_W = (1/T) Σ[t∈A] Σ[i covers t] α_it (p_i(t)−y_t)^2 + λ̄ ||B_free||²
J_F = (1/T) Σ[t∈A] (p̄_t−y_t)^2                    + λ̄ ||B_free||²
```

同一物理点最多两窗贡献，故数据项精确满足`J_W−J_F = mean_A[Σ_i α_it(p_i−p̄)^2]`，共同正则抵消。F去掉的是逐窗加权损失所含的disagreement项，并不是额外一致性惩罚；F可能允许较大disagreement来换取融合误差下降。所有r、融合/加权单窗MSE、disagreement均报告，不用其中一个替代其余。

D8原岭目标为`(1/N)Σ[i≥4] ||y_i−p_i||² + .01||B||²`，这里192个输出求和；整体除192，得到统一window mean-MSE与等价正则`.01/192`。**只有对同一完整192窗/样本支持整体缩放时，该换算保持最小点。** D9的物理点等权、Hann贡献计权、固定边界和零端点约束不同，不能把W/F称为与D8完全相同经验目标或相同有效正则强度；λ̄只作为预先固定的共同scalar尺度，无重新搜索。

本轮只有W/F两个匹配目标；原window-PCC不新增为优化角色，故不能由W/F差异证明原Pearson导致标度失败。原统一window MSE/D8强Ccap作为只读不同支持参考，不把它与新目标的差值写成纯损失单因素效应。

## 4. 端点、自由bias及可识别性

Hann使输出列0、191永远无正贡献。两臂均将这两列的B和bias**固定为原D8初值**，不让无监督端点因正则被隐式压零；其正则是共同常数，单列记录。拟合自由度为3264×190+190=620350参数；6530个端点参数固定。它们在辅助3秒r中仍使用相同初值，在Hann主评分中权重0。

融合只把列j与j+96耦合，共96对，不形成任意626880维稠密系统。其余bias不添加隐藏正则。由于每记录第一可学习窗与固定前邻居、最后窗的单覆盖边界均保留，理论上为每对有效bias提供边界约束；实际先检查对应1×1/2×2 bias Hessian的rank/最小特征值与条件数。若仍有精确null方向，两臂共同将其投影冻结在D8初始化并明确记录，不擅自加ridge到bias；新额外约束须先说明，不能宣称唯一解。正λ与实际bias正定条件经核对后才能讨论自由空间的唯一最小点。

## 5. 求解器、步长、收敛与公平性口径

固定特征下两目标都是二次式，用FP64 matrix-free preconditioned conjugate gradient求正规方程，避免稠密构造Hessian或新NN优化器网格。设A将自由B/b映射到窗口增量，H将完整窗口按原α融合至共同物理点：

```
W Hessian action: Aᵀ diag(α/T) A δ + λ̄ D δ
F Hessian action: Aᵀ Hᵀ H A δ / T  + λ̄ D δ
```

RHS由共同真实y和固定q/端点贡献一次构造，D只惩罚自由B。以原D8参数为共同x0，CG精确二次步长`step=(rᵀ M⁻¹r)/(pᵀ Hessian(p))`，没有经验学习率或VAL择步长。共同Jacobi预条件由D8 TRAIN未中心化特征二阶矩`diag(G)+mean²`构造，B对角`moment/192+λ̄`、bias对角`1/192`；不按W/F分数选择预条件。

每解上限200次CG更新、214次Hessian作用（含初值、每20步与末次真实残差检查）；停止门为真实预条件残差相对RHS范数≤1e−8，分母下限1e−30，只用TRAIN。所有迭代/真实残差/目标与代数组分解保留。达200仍有限但未过门则保存并评分一次，标`FIXED_CAP_NOT_CONVERGED`，不自动增加迭代/换预条件/λ；只有两臂都达到相同真残差标准，才把差异解释为已求解目标的比较，否则仅是固定上限下的有限优化诊断。

实际迭代可能不同，不能声称等SGD更新、等epoch或等实际算力；共同的是初始化、数据/参数权限、目标支持、正则、残差标准与上限。精确记录每臂Hessian次数、X/XT乘次数、RHS/目标检查与唯一目标点数；Hessian作用不重新读取y，但使用已由y形成的RHS，不把多次计算等同新的独立标签或将额外代价隐去。
