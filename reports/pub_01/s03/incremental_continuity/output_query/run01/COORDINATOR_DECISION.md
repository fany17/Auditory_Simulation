# D22：输出历史的非线性竞争对照

2026-11-06，整体研究目标保持 ACTIVE。D20 的三个 seed 均高于 FT+Ccap，开发 r 均值 0.184090511；D21 的线性 F 只有 0.182905028。D21 独立分块审计还显示，D20 的平均主指标增益 0.001750571 中，0.001574155 来自 703 个纯活动块，不能主要归结为前缀衔接。线性对照较差仍不能证明 D20 的当前 EEG latent query 是必要成分。下一步只增加一个有明确竞争意义的非线性输出-only 对照，不据此宣称新架构创新。

## 具体比较

B 仅把 D20 当前 query 的 8 维 g(t) 改为当前冻结预测 b(t) 的一个标量。当前和历史都来自同一个冻结 FT+Ccap，不使用真实过去包络。当前输入先取 float32，再用同 seed D20 P 的 TRAIN-only 标量统计归一化；96 个四点历史箱仍为 b[t−384:t]，同样沿用 D20 历史统计。残差加回的锚点保留 float64。

q = GELU(Linear(1,32)(b_norm))；c = Linear(64,32)(GELU(Linear(96,64)(h_norm)))；预测为 b(t) + Linear(32,1)(GELU(Linear(32,32)(q * (1+tanh(c)))))。

先按原 seed 构造 D20 PhysicalDecoder。context、mix、output 和 current bias 逐值保留；新的 current weight 为原 current weight 第一列乘 sqrt(8)，以匹配单输入的 fan-in 权重尺度。其余七列移除，实际参数为 9,441，D20 为 9,665。保留公共参数初始化，不称全部初始参数或参数量相同；输入维数和输入层初始化变换仍是比较限制。额外层构造不得污染后续 RNG；初始化残差必须精确为零。

所有既定 TRAIN426/VAL49、first_active1344、批次顺序、float32 TRAIN 目标、float64 物理 SSE、每批除以16384、Adam 设置、20 pass、固定 TRAIN 检查点、每轮 VAL 与最早严格最优（含锚点回退）沿用 D20。三个 seed 为 1024/2026/31415。D20、D21 直接作为冻结参照，不重跑。三组正式应共 86,820 更新和 1,422,210,600 个反向目标点；输入重建、评估与工程各自实计。固定历史替换保留近 lag1、远 lag288、相同当前 b/query/cache 和相同归一化，不按结果新增 lag 或预算。

## 实现与核验范围

优先复用冻结 fit_role 和 evaluate 函数。局部代理仅替换实际模型/输入与 PARAMETER 计数，原冻结模块文件和对象不被全局改写。训练、验证与缓存 current_code 必须使用同一 scalar Table 与统计，不能只修改训练 forward。

正式前核验完整新源码及实际有限工程：实际 Record/Table latent 路径在固定 b/历史下改变不影响 B；b 改变能影响当前码；共享参数、RNG 与原 seed 排列一致；显式标量归一化和历史分箱一致；零头和非零头梯度有效；原锚点与评分端点一致。工程结果绑定冻结协议后直接正式执行，不重复索取用户授权。

正式后应独立核对真实三 fit、逐轮/逐人指标、预算、选点、实际 checkpoint 及有限功能重放。混合前缀与纯活动块分解只作描述，不替换原主指标或用于另选点。报告 r 与 MSE 的异向结果。即使 B 达到或超过 D20，也只支持输出-only 非线性竞争解释；即使 B 落后，也不能独立证明过去 EEG 特异信息、所有非线性输出基线均已排除或独立泛化。

所有信号数值和训练在 2203 独立新目录，Windows 仅代码和轻量结果。仅既有合法 TRAIN/VAL，旧测试、DTU、ds004408 和其他冻结实验不重新开启。D22 是机制与竞争基线检查，总体要求仍是可重复优势、泛化、消融、完整成本和可评估的创新证据。
