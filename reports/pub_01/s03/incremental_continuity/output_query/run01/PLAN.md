# D22 输出端非线性竞争对照

2026-11-06 · PUB-01-S03_SS07 · B 单角色

D21 的输出端线性 FIR 在三个 seed 超过仿射与原锚点，仍低于 D20。D22 比较相同非线性历史门下，仅用当前冻结预测 b(t) 的 B 与使用当前 8 维 g(t) 的 D20。要检验的是输出端非线性在相同开发协议能否匹配 D20。即使出现差距，也要考虑输入维数、第一层尺度和可表达性，无法直接识别当前 latent 的独立机制。[D21](../../output_ridge/run01/REPORT.md) · [D20](../../recent_prediction_context/run01/REPORT.md)

## 冻结协议

- B 当前 query 仅输入当前 b(t) 的 FP32 标量。近历史仍是 b[t−384:t] 的 96 个有序四点均值，保持 D20 lag1。当前和历史均使用同 seed 原 D20 P 的 TRAIN-only 标量统计。b(t) 作为残差外的加项仍为 FP64。原 FT+Ccap 锚点、原 TRAIN/VAL、起点 1344、原物理 MSE 与块人宏 r 全部沿用。
- q 为 Linear(1→32)+GELU。历史 Linear(96→64)+GELU→Linear(64→32)。融合为 q 乘 1+tanh(context)，再经 Linear(32→32)+GELU→Linear(32→1)。实际 9,441 个参数，D20 为 9,665。首先构造同 seed 的冻结 D20 网络，保留所有共享张量与当前 bias，新的 current.weight 取原第一列乘 √8。构建 1 维层的随机消耗用 CPU fork_rng 局部隔离，原 CUDA 状态保留。
- B 在历史和当前使用同一个冻结预测来源。改动原 latent g 并固定锚点后，不应改变 B 的输入和输出。调整 b 应改变当前码。仅在非 −1 的选中模型上比较近/远，替换 lag288 时复用同一当前码和 D20 近历史统计。
- 沿用 D20 的三 seed、20 pass、全局无放回顺序、固定 batch 分母、Adam、原 anchor epoch −1 与最早严格更好的选点规则。正式训练与评估通过冻结 fit_role 的原字节码和签名执行，独立本地 globals 只允许实际 B 参数计数 9,441，供给 B 构造器。原模块对象、代码与所有源文件不变。评估调用原 evaluate 与同一个 B 输入表。

## 预算与工程

2203 独立 writer 为 `/sata5/fanyu/auditory_simulation_m6a/pub_01/s03_output_query_20261106`，单卡绑定 GPU UUID。原 D20 预算为 3×20 pass、86,820 更新、1,422,210,600 个训练反传点、284,442,120 固定 TRAIN 与 172,007,940 逐轮 VAL 评估点。若有非 −1 的选中模型，每 seed 再做固定当前近远，最多增加 8,600,397 当前 stem 点及 17,200,794 上下文输出点。合计上限为 1,887,261,057 stem 和 1,895,861,454 上下文输出。新 EEG encoder 与原 FT 神经头前向为 0。

有限工程只读每 seed 前两 TRAIN 记录，共 6 条及 3,447 缓存窗，无 VAL。对照显式 FP32 标量与四点分箱、全局 ID 跨记录、g 扰动不影响输出、b 扰动改变当前码、固定码近远替换、零头与临时非零头梯度、原共享张量及 CPU/CUDA RNG、原 D20 实际初始化指纹与首轮排列结束状态。预算 36,960 个当前 stem 点（含 96 个当前码 canary），49,152 个上下文输出点、24,576 个 backward 点及 0 更新。正式须绑定独立源审阅和真实工程回执。

正式保留逐 seed、逐人、所有轮次和固定 TRAIN 指标。后置描述性比较混合锚点前缀与纯活动块，不影响选点。D19/D20/D21/D9/D18 作为已冻结证据。结果限于既有离线、反复使用的开发 VAL，与原 EEG 的最晚权限保持一致。
