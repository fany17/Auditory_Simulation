## 已知事实、假说与目的

D15 的 H 三 seed 全部回退 Ccap，不能建立历史收益。H1024/2026 后期抽查 token/GRU 梯度精确零，H31415 的末轮首批 GRU 范数约 1.10e-14；初期非零与后期退化并存。D14 固定小批旧权重探针另见极大的 token 值、近饱和 GRU 状态及零/极小输入梯度；fresh 非零输出探针证明计算通路本身可微。这些证据支持检查隐藏特征尺度，尚未证明它是全部性能差异的原因，也不能外推所有样本。

下一假说：约束进入 GRU 的每个 token 的特征尺度，可能维持可学习的历史通路。训练稳定性与任务收益是两个不同终点，均须实际检验。归一化本身是已有方法，不作为 ICML/NeurIPS 创新或目标完成依据。原论文介绍了 Layer Normalization 对循环网络状态稳定性的用途；本轮只是输入 token 处的无仿射适配，并非复现其完整归一化 RNN。[Ba et al., Layer Normalization](https://arxiv.org/abs/1607.06450)

## 唯一网络改变

以 D15 完整 FT+Ccap、三臂条件器为基底。只在现有 token 网络末端 GELU 之后、两步 GRU 之前加入：

```python
tokens = F.layer_norm(tokens, (32,), weight=None, bias=None, eps=1e-5)
```

对 B×2×32 的最后 32 个特征分别操作，不跨 batch、两个时刻、记录或 split 估计统计；不保存 running statistics，不学习仿射参数，不裁剪输入，不改 GRU、FiLM、当前分支或输出。按 PyTorch 2.11 定义使用 correction=0 的方差、sqrt(var+eps)，训练与评估使用相同逐输入统计。[PyTorch LayerNorm 文档](https://docs.pytorch.org/docs/2.11/generated/torch.nn.LayerNorm.html)

H/C/P 全部加同一操作，新增可训练参数为零，原参数数目与 RNG 初始化保持相同；新增归一化算术和运行时间须披露，不能称 FLOPs 完全相等。它也改变表示的尺度/平移信息与函数约束，不应包装成纯优化器干预。只测这一位置/eps/无仿射版本，不增加位置、LR、正则、损失或新架构网格。
