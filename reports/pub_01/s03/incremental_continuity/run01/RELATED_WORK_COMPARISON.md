# SS07 一手相关工作与方法边界（2026-11-01）

当前尚无完整SS07主测试结果，方法新意和投稿充分性均未成立。以下是实际浏览一手论文后，对照已冻结代码得出的比较；不新增模型、训练目标、数据、超参或实验门，不声称穷尽相关工作。

## 1. 已核验来源及其适用范围

所有链接于2026-11-01实际读取；版本写在链接中，避免将不同版本的实验条件混用。预印本不自动视为同行评审或已复现结果。这里只概述方法与可比性，不搬用论文分数排榜。

| 一手来源与读取位置 | 已核实的相关方法事实 | 对本轮的限制/推断 |
|---|---|---|
| [SHINE v2](https://arxiv.org/html/2602.23960v2)，§3、§4.2–4.4 | 多层膨胀卷积、局部/上下文两路及逐目标/时间门控；30s输入，整record标准化，pooled r | 多尺度和动态上下文融合已有先例。其Sparr split263/207/192、联合包络/Mel与本轮不同，不能直接比r或称复现 |
| [DECAF v1](https://arxiv.org/html/2602.19395v1)，§3.1–3.2 | 用过去融合输出递归构造包络prior，与当前EEG分支作凸门控融合；3s窗、500ms EEG偏移、80%训练重叠、L1与Pearson联合目标 | 递归输出先验不是本轮首创。其窗口/目标/训练及测试聚合与本轮不同，不能引用其r作为同协议基线 |
| [Transformer-XL](https://aclanthology.org/P19-1285/)，论文摘要/正式元数据 | 分段递归及位置编码用于超出固定上下文的语言建模 | 跨segment保存状态是既有思想；SS07没有实现Transformer-XL，也不能据此借用其语言建模效果 |
| [CPC v2](https://arxiv.org/abs/1807.03748v2)，摘要 | 自回归上下文预测未来latent，采用带负样本的概率对比目标 | 未来表征预测不是新概念；SS07 M3是标准化摘要MSE辅助项，不是CPC对比目标复现 |
| [Dynamic Filter Networks v2](https://arxiv.org/abs/1605.09673v2)，摘要 | 根据输入动态生成滤波器，可组合为递归结构 | 历史条件化变换不是新的通用运算原理；与M4的联系是方法层推断，不是同模型或性能复现 |
| [KalmanNet v3](https://arxiv.org/abs/2107.10043v3)，摘要 | 将部分已知状态空间结构与递归网络结合进行状态估计 | SS07 M5无该已知动力学结构、校准协方差或最优性保证，不能称KalmanNet或Kalman filter |
| [Lin与Li：S4+U-Net](https://yueqianlin.com/assets/files/ncmmsc23.pdf)，§2、§3.2 | EEG包络重建已组合S4、U-Net和subject modulator；§3.2采用双向S4与5s分段后拼接 | state space/denoising本身不构成新意；分段双向处理不等于本轮跨窗持久历史。cohort、预算和表述不同，不直接比数值 |
| [Yao等MSM v1](https://arxiv.org/html/2602.13447v1)，§II、§II-A/B | 注意状态Markov连续性与EEG/两候选包络关系联合建模，forward-backward及EM推断；正文明确平滑可利用未来 | 状态连续性在AAD已有先例。但候选音频参与的sAAD与仅EEG包络重建不同；文中另述只做forward可因果化，不把完整平滑当严格在线 |
| [Liang等contrastive PCC v3](https://arxiv.org/html/2601.20542v3)，§2.3、§3.2–3.3 | 优化attended/unattended相关差，使用多说话者真实包络；目标域内交叉验证训练、128Hz预处理 | 关注可分性不等于attended r；其DTU内训练与本轮无目标域拟合/64Hz适配不同。辅助accuracy不能直接排榜，Sparr单说话者不追加该loss |

Lin与Li原文还有一个应保留的来源差异：§3.2写式2中α=1/3，而Table1最后一行within=.2040、heldout=.1258、score=.1779；按式2的S1/S2顺序，α=1/3并不产生该score。因此这里不据该文字替本轮重新解释权重，也不修订原论文。此为文内一致性问题的算术核对，不是本轮实验结果。

## 2. 本轮真实实现与可辨识的比较

本地权威来源为 `scripts/pub_01_s03_ss07_incremental.py`、`pub_01_s03_ss07_train.py`、`pub_01_s03_ss07_select.py` 及本轮INCREMENTAL_PROTOCOL。以下描述来自实际代码；论文之间的关联是本报告的解释，不是作者声明。

| 候选/控制 | 已冻结的实际运算 | 必须避免的过度命名；本轮可检验的问题 |
|---|---|---|
| M1 | 48维EEG摘要→四个3/12/48/192s EMA→历史条件8×8残差混合→原head | 多尺度本身不新；检验真实非重叠历史是否超出同当前窗/容量控制 |
| M2 | GRU与可学习慢EMA组成历史上下文，同样生成8×8混合 | 不称新递归原理、Transformer-XL或官方DECAF复现；需要实际五seed控制差值 |
| M3 | M2型上下文的after-state预测i+2的48维摘要，train-only标准化MSE辅助；相同有效tail mask的current-teacher控制 | 不是CPC/InfoNCE、纯无监督模型或在推理时看到未来；检验future目标是否优于同预算current目标 |
| M4 | 历史输出8×3无约束系数，对latent时间轴4/8/16点移位差作0.1倍加和 | 不是物理延迟估计、凸滤波权重或硬件对齐证明；只检验动态特征变换是否超出静态移位组合 |
| M5 | 从历史生成latent prior，并以历史条件矩阵作用于z−prior，保留prior-only控制 | prior没有独立条件均值/不确定性校准保证，不称Bayesian创新或最优Kalman增益；latent减法本身不足以证明预测编码机制 |
| output_prior | core读取每窗原head(z)摘要，预测六点输出残差并插值，加到当前head(z) | **没有把过去最终融合输出递归反馈**，也无DECAF凸门控/同backbone/同目标；只能约束本实现中的神经输出历史解释，不能声称战胜完整DECAF |
| current/static/EMA/FT | 同当前窗条件core、active容量静态adapter、验证固定tau平滑、完整原encoder+head微调 | 匹配参数不自动匹配全部FLOPs；本轮账本单列搜索、共享预训练和推理成本。即使主模型胜出，也仅约束这些实际控制 |

8×8矩阵由上下文投影产生，但没有rank<8的约束；不能把它称为已实现的低秩算子。0.1残差系数也不是增益有界或稳定性定理。以上命名界限不改变现有网络，只使结论与代码一致。

时间支持方面，当前窗i的原始输入是[96i,96i+192)。同parity历史最新为i−2，其输入结束于96i；这是本轮“不重复当前原始支持”的工程契约。**它不使整个离线系统逐sample因果**：原Transformer在整个3s当前窗内双向使用信息，Hann融合保留原窗支持。current条件控制也可以使用整个相同当前窗。M4在latent轴移动特征不能撤销这种支持或建立生理时间解释。

## 3. 仍需由真实结果回答的问题

本轮可能贡献的是：在完整强表征和原head完成预设全量训练预算后，以相同当前输入权限、明确的非重复历史支持、匹配控制与固定历史干预，判断历史是否提供稳定的额外信息。五head均达到250epoch预算上限、FT五seed均最佳在末轮，未证明收敛或当前信息已被最优利用。该问题与方法组合的研究价值仍需证据；上述文献差异本身不证明新算法或论文级创新。

结论必须同时面对FT强控制、容量/输出先验解释、全部五seed和共享刺激依赖、DTU固定适配及实际raw/metric复核。若差值不稳或仅验证改善，不能改名、挑seed、改终点或用相似论文的好看分数补足证据；按已有协议报告事实，保持原研究目标与明确的投稿缺口。

此文件只做来源与可比性核验；不下载任何新增数据/权重，不新增baseline或loss。完整官方DECAF/SHINE等在同协议下的直接竞争结果目前缺失，尚不能声称SOTA。新候选或后续实验如有科学必要性，仍须回到现有parent scope和已授权有界矩阵判断，不能由本文自动启动。
