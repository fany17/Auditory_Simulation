# D26 强对比预训练中的历史联合学习

按 [协调决定](COORDINATOR_DECISION.md) 执行。6 个唯一对比预训练以 seed 为单位，H 与 C 分占两张 L40，各自使用原完整 128×128 对比损失和固定 VAL 对比批。CH 与 CC 共享 C 的选中预训练，分别生成对应历史路由的缓存、配对训练 head 与完整 5 轮 FT。C 侧在同卡顺序推进 CH、CC 每轮 head。正式缓存为内存，监督训练保持全局 64 原顺序和尾批。

TRAIN 426 / VAL 49、监督 252,454 / 30,500 窗、原对比 820 / 98 批已验证。每个监督 TRAIN / VAL pass 中历史可用 248,620 / 30,059 窗。CL 每轮实际记账，并跨轮按记录和时间合并唯一点。H/C 保持当前、两个 slot 与音频实际前向次序及各自 dropout。总 CL 参数 3,817,609，监督 encoder+memory 3,389,256，head 257。前缀由新模型本身的当前分支输出。

最终比较 epoch 4 的原始 FT、正仿射 P 与新 TRAIN-only Ccap。按三 seed 的固定最终均值选一个完整臂，平分取 CC、CH、HH。HH 共用当前 query 做远历史和当前复制干预，保留原 752 块主评分，另从物理点 960 起评分，排除前缀与历史融合过渡区。

上限见 [预算](BUDGET.json)。CL 每 256 步、head 每 1,024 步、FT 每 512 步及轮末保存模型、优化器、调度器、Torch CPU/CUDA RNG 与游标。从已提交边界恢复，异常后未提交的成本另列。正式控制器不自动重启。SATA 新目录上限 64 GiB，至少保留 64 GiB，每 worker CUDA 40 GiB、RSS 32 GiB。所有新计算在 server2203。
