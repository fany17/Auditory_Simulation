## 1. 唯一问题与证据边界

假说：只用当前 3 秒 EEG 完成跨模态对比预训练，可能没有保留需要与当前联合使用的历史表示；在同一原强模型、同一当前 XLSR 目标下，让严格过去的 EEG 路径共同接受对比梯度，可能改善后续 EEG-only 包络重建。此为待检验假说，不是已有收益或新颖性结论。

已读原服务器 `pub_01_s03_transformer_train_v2.py`：StoryBatches 只给当前 EEG 和对应的 192 点音频特征；原 TransformerCLIP 的 EEG 与 SpeechLSTM 两侧共同训练，使用双向交叉熵。D18 历史来自冻结 E0，监督阶段才加入。SS06 M3 已有连续 EEG 自监督，SS07 warm 已有历史条件下端到端监督微调，故不能称首次连续性预训练或首次端到端。

[SHINE](https://arxiv.org/html/2602.23960v2) 的长上下文与包络/Mel 联合回归、[DECAF](https://arxiv.org/html/2602.19395v1) 的 EEG/包络 forecaster 融合已覆盖多种相关组件；它们不能证明此处的 XLSR 对比阶段改动有效或新颖。当前只研究训练阶段的具体缺口。输入功率增益方案暂不实施，不增加并行架构搜索。

## 2. 数据与共同模型

仅原合法 SparrKULee TRAIN 426 / VAL 49、原 TRAIN 通道统计、原现有 XLSR19 特征和原包络目标。逐项核对实际清单、记录坐标和来源后冻结。原 252,454 TRAIN / 30,500 VAL 监督窗、49 人 / 752 VAL 块及预测无关 mask 均保留，不择样本、不改 lag、不拟合 VAL 统计。所有结果都是重复开发 VAL 上的探索；旧 test、DTU、ds004408 不读取、不重评。

保留原 native 3 秒 offline EEG backbone、64→8 projection、SpeechLSTM、log scale 和完整对比损失，不换小 encoder。三 seed：1024 / 2026 / 31415。EEG、音频投影和增量模块均从头初始化，不能加载旧 FT/EEG 权重。

在 D18 已有 `192×64` projection 前位置，复用其固定 64 维/8 heads TokenMemory 结构、归一化、相对位置编码和零输出初始化。当前与两段历史由**同一个可训练 EEG encoder**编码，不用冻结 E0、detach 历史或事先缓存训练态历史。输出仍为当前 192 点的 8 维表示。三臂参数完全相同；列出实际总参数、对比阶段/监督阶段活动参数和实际前向次数。

当前起点 s；近历史原始支持为 `[s−480,s−288)` 与 `[s−288,s−96)`，远历史为 `[s−864,s−672)` 与 `[s−672,s−480)`，64 Hz。统一 `s≥864` 才启用 memory。此前所有窗仍以**该新模型自己的当前分支**参与训练/预测，三臂同样绕过 memory；不得拼接旧强模型前缀。此几何保留 D18 near5/3、older9/7，在监督 hop96 上相当于 i≥9，历史与完整当前 Hann 贡献支持无重叠。预训练若不是 hop96 网格，也按实际 s 判定，不按样本序号误推时间。

不声称完全因果：当前3秒模型、原 XLSR 特征及历史数据预处理均保留既有 offline 权限。相对位置只用窗内/相对坐标，无绝对 story/record ID 或 target-derived index 输入。

## 3. 固定最小矩阵

| 臂 | 对比预训练 memory | 后续 head / FT / 评估 memory | 用途 |
|---|---|---|---|
| HH | 真实近历史 | 真实近历史 | 预训练历史候选 |
| CH | 当前 EEG 两次复制 | 真实近历史 | 历史仅在监督阶段加入 |
| CC | 当前 EEG 两次复制 | 当前 EEG 两次复制 | 同容量当前控制 |

每 seed 仅两个唯一预训练 H/C；CH 与 CC 从同一 C checkpoint 分叉，独立 head/FT。合计 **6 个预训练、9 个 head、9 个 FT、9 个固定 Ccap 读出**，不是另加五框架或宽度/时长/损失网格。共享预训练成本只计一次，逐臂摊销另列。

为匹配实际训练计算，C 也实际执行三次共享 encoder 调用（当前 query、两个当前副本 memory），并让这三条真实参与预测的路径接受梯度；不以无用前向凑 FLOPs。各调用 dropout 独立，调用次序、张量形状和 RNG 规则在 H/C 配对中一致。推理可复用完全相同当前编码时须另列实际与可优化成本，不能将训练态随机副本简单当成可无损缓存。重复当前信息及 dropout 本身可能构成有力控制，不能隐瞒。

HH−CH 检验在本实现下让历史进入对比阶段的价值，但 CH 的阶段切换也改变了 memory 输入分布，不能单独归因表示机制。HH−CC 检验相同结构/预算下真实历史相对当前副本的价值。另与原三 seed FT+Ccap 强锚点作绝对性能比较，明确锚点容量、训练过程和成本差异。

## 4. 训练目标、停止与选点

**对比阶段**：保留原同 story 的 128 个不同时间作为全局 negatives；同 timestamp 的不同被试不能互作负例。严格复现原 plans/抽样当前 row、seed+epoch 顺序、当前 target、音频侧和对称 CE；历史必须来自该 row 的同一记录。原则上每 epoch 820 次更新，实际核实后冻结。AdamW lr .001 / wd .01，无 clip，StepLR10 / gamma .1，最大100 epoch。

每 seed 的 H/C 使用**配对共同停止**：逐 epoch 各自在固定 VAL 对比批（原 seed20261015）上记录是否改善；只有双方各自均连续15轮无改善才同时停止，最迟100轮。两臂必须到达同一 epoch 才判断，不能将速度差当预算差。各自选择最小 VAL 对比损失 checkpoint，同分取更早。此共同停止是显式预算匹配修订，与旧 native 单臂 patience 的实际更新数不必相同；不得声称所有成本与旧锚点完全相等。保留全轨迹和实际重复样本数。若全局128需分块构图，必须一次完整128×128 CE、一份梯度/更新，不能变成多个小负例矩阵。

**head阶段**：冻结各自 pretrained encoder/memory，分别产生对应路由的 TRAIN/VAL latent；原 Conv1d(8,1,32,same)+LeakyReLU .01，三臂同 seed head 初始化；原 global64、manifest/time 顺序、Adam .001 / wd0 / no clip；原 float32 centered negative cosine eps1e−6，最大250 epoch。每 seed 三臂共同停止，只有三者各自均连续10轮无改善才一起停止，最迟250；各自以原按窗口加权 VAL objective 选点。不是60秒指标选 head。保留 head 到达预算上限未收敛的事实。

**联合监督 FT**：三臂各从所选 pretrain/head 开始，当前和 history encoder 共享且全可训；固定完整5轮、每轮原252,454窗/3,945次更新。Adam：原 encoder（含projection）lr1e−5、memory lr1e−5、head lr1e−3，wd0/no clip/no shuffle；原 float32 3秒 centered negative cosine eps1e−6。memory 与表示共同微调，不引入独立高学习率搜索。保存 epoch−1 和各轮原 VAL objective，最好点可作未校正 native 描述；**主要最终比较固定使用 epoch4**，不以新 VAL/对比结果追加预算。

**固定读出**：对每个最终 epoch4 的新表示，沿用 D8/D24 已审的 TRAIN-only 正仿射校准和 Ccap 构造/λ=.01，重拟合其所有 latent/P/平方统计与系数。9个读出各一次，不套旧系数、不扩 λ、不因 VAL 下降回退或换点。保留原 i≥4 拟合/作用与前4窗该模型 P 回退；历史未就绪前仍是该新模型自身的 local 输出。逐臂交付 native FT、正仿射 P 和 Ccap，不能只呈现校正后的最优数。

## 5. 固定评价与判定

主表：三臂各三 seed 固定最终 Ccap 的原完整 VAL60秒→person r、与 CC/CH/旧同 seed 强锚点差值；同时报告 native/P、MSE、共享源族29条与未见源族20条（按实际 SOURCE_FAMILY_JOIN 核实）及每来源、每人。不重新选择 split 或 source，不把多个 seed 当独立被试。完整训练/选择轨迹要保留，独立重复验证中不宣称确认性 p 值。

HH 最终模型另执行两种预定无训练干预：近历史→远历史、近历史→当前复制。保持当前 raw EEG/query/projection路径、模型权重、Ccap及评分坐标相同；缓存当前 query，避免重复随机性/数值路径造成伪差。远历史使用同相对 slot code，故同时包含输入分布/时间差异，不能称纯时延因果效应。只对有共同近远支持的活动区域解释历史干预；原完整49人/752块主评分不改变。早期窗不靠旧 anchor 凑分。

性能主决策：按三 seed 的固定最终 Ccap 开发 r 均值，在 HH/CH/CC 中选择最高者，同分按预定顺序 CC、CH、HH。与原同 seed 强锚点及其余两臂报告完整逐seed/逐人差值，不只给赢家。只要均值超过锚点即记录为性能进步线索并评估后续同协议强方法对照，不再要求收益必须来自历史；seed方向混合、来源集中或选择偏差须明确，不能写成稳定确认。若三个seed均正则另记录方向一致。无正增益则本矩阵不支持改进，保留所有结果。固定最终值与选择过程已事先定义，CL loss 或临时峰值不代替最终包络性能。

历史贡献是次级问题：只有 HH 对 CH/CC 的匹配差与固定当前的历史干预共同支持，才作相应有限解释；不满足也不阻止更强的 CC/CH 性能候选。所有阴性/失败如实保留；本轮结束即停止此固定矩阵，不自动扩宽度/历史长度/预算/损失或再开旧测试。开发线索不等于SOTA，后续需最新强方法的同任务可比评估，且要披露反复开发和全部成本。
